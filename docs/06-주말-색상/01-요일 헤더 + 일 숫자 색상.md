# 단계 1: 요일 헤더 + 일 숫자 색상

> 새로 배울 Swift / SwiftUI 개념 없음 — 작업 가이드만.

## 작업 목표
- 요일 헤더 "일" → 빨강, "토" → 파랑, 나머지 → 기존 `.secondary` 유지
- 일요일 칸 숫자 → 빨강, 토요일 칸 → 파랑, 평일 → 기존 `.primary`
- 이번 달 외 (`isInCurrentMonth == false`) 칸은 **흐림이 우선** (`.tertiary` 그대로) — 색상 분기보다 우선

## 사전 지식
- `MonthlyCalendarView.swift` — 요일 헤더 ForEach 가 있음
- `DayCellView.swift` — 셀 텍스트 색상이 `foregroundStyle(...)` 로 결정됨
- `CalendarMath.swift` — `DayCell.date` 가 살아있음 (요일은 여기서 뽑을 수 있음)

## 구현 가이드

### A. 요일 헤더 색상 (`MonthlyCalendarView`)

현재:
```swift
ForEach(weekdayLabels, id: \.self) { label in
    Text(label)
        .frame(maxWidth: .infinity)
        .foregroundStyle(.secondary)
}
```

label 만으론 일/토 구별이 어색하니 **인덱스로 도는 방식** 으로 바꾼다:

```swift
ForEach(weekdayLabels.indices, id: \.self) { i in
    Text(weekdayLabels[i])
        .frame(maxWidth: .infinity)
        .foregroundStyle(headerColor(at: i))
}
```

색상 분기:
- `i == 0` → `.red`
- `i == 6` → `.blue`
- 그 외 → `.secondary`

`headerColor(at:)` 는 `private func` 으로 빼면 깔끔. 한두 줄짜리면 인라인 삼항도 OK.

### B. 셀 숫자 색상 (`DayCellView`)

요일을 알아야 하는데 두 가지 선택지:

**선택 1 — `DayCell` 모델에 `weekday: Int` 추가** *(권장)*
- `CalendarMath.swift` 의 `DayCell` 에 `let weekday: Int` 필드 추가
- `makeDayCells` 의 셀 생성 부분에서 `let weekday = cal.component(.weekday, from: date)` 로 계산해 넣기
- View 가 깨끗해짐. 04 의 `Category` 모델 패턴과 일관.

**선택 2 — View 에서 매번 계산**
- `Calendar.current.component(.weekday, from: cell.date)` 를 `DayCellView` 안에서 호출
- 모델 변경 없음. 다만 View 가 Foundation 의 `Calendar` 까지 알게 돼서 결합도 ↑

→ **선택 1 추천**. 어차피 한 번 계산해두는 게 자연스럽고, 후속 기능 (주말 강조 / 공휴일) 에서도 재사용.

### `weekday` 값 메모

`Calendar.current.component(.weekday, from: date)` 의 결과:
- 1 = 일요일, 2 = 월요일, …, 7 = 토요일
- (이미 `makeDayCells` 가 `leadingDays` 계산할 때 같은 방식 사용 중)

### 색상 결정 로직

DayCellView 안에 computed property 로 빼두자:

```swift
private var textColor: Color {
    if !cell.isInCurrentMonth { return .secondary }   // 흐림 우선 (또는 .tertiary)
    switch cell.weekday {
    case 1:  return .red
    case 7:  return .blue
    default: return .primary
    }
}
```

> 이번 달 외 칸을 **회색으로 통일** 할지, **이번 달 외 + 주말 색** 으로 표시할지는 디자인 선택. 일단 회색 통일 (`.secondary` / `.tertiary`) 로 가고, 시각 보고 더 손볼지 결정.

그리고 `foregroundStyle(textColor)` 로 한 줄 대체.

## 자가 점검
- 헤더 "일" 빨강, "토" 파랑인가? 나머지 회색인가?
- 일요일 칸 숫자가 빨강, 토요일 칸 숫자가 파랑인가?
- 이번 달 외 (앞뒤 회색 칸) 의 일/토는 어떻게 표시되는가? — 의도한 디자인과 일치하는가?
- 다크 모드로 전환 시에도 보기 OK 인가? (SwiftUI 의 `.red` / `.blue` 는 시스템 컬러라 다크모드에서 톤 자동 조정)
