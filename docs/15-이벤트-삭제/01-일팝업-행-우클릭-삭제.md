# 단계 1: 일 팝업 행 우클릭 → 삭제

> 새 개념 없음. [09-06](../09-폴더-카테고리-데이터-영속화/06-삭제.md) 의 `.contextMenu` + `modelContext.delete(_:)` 패턴을 `DayPopupEventRow` 에 그대로 적용.

## 작업 목표
일 팝업의 이벤트 행을 마우스 우클릭하면 컨텍스트 메뉴에 "삭제" 가 뜨고, 누르면 즉시 삭제된다. 일 팝업의 `@Query` 가 변경을 감지해 행이 자동으로 사라진다.

## 사전 산출물
- `DayPopupEventRow` ([12 / 14-12](../14-멀티데이-이벤트-렌더링/12-일-팝업-멀티데이-포함.md)) — `event`, `date`, `onClick` 받는 행 뷰.
- `DayPopupDialog` 의 `@Query` — `event.startDate < dayEnd && event.endDate >= dayStart` 로 그날에 걸친 이벤트들을 자동 갱신.

## 작업 가이드

### 1) `DayPopupEventRow` 에 `modelContext` 주입

```swift
struct DayPopupEventRow: View {
    @Environment(\.modelContext) private var modelContext   // 추가
    @State private var isHovered = false
    let event: Event
    let date: Date
    var onClick: (Event) -> Void
    // ...
}
```

### 2) `.contextMenu` 부착

행의 가장 바깥 컨테이너 (즉 `HStack { ... }.modifier-chain` 끝부분) 에 `.contextMenu` 추가:

```swift
.contextMenu {
    Button("삭제", role: .destructive) {
        modelContext.delete(event)
    }
}
```

- `.onTapGesture` 와 충돌 없음 — 좌클릭은 onTap, 우클릭은 contextMenu.
- `role: .destructive` → 메뉴 항목이 빨간색 + 위험 액션으로 인식.
