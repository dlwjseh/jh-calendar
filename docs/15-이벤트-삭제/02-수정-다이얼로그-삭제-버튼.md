# 단계 2: 수정 다이얼로그 안 "삭제" 버튼

> 새 개념 없음. `.edit(Event)` 모드 분기 + `modelContext.delete(_:)` + `onDismiss()` 조합.

## 작업 목표
이벤트 수정 다이얼로그 좌측 하단에 destructive 스타일의 "삭제" 버튼을 둔다. 누르면 즉시 삭제 + 다이얼로그 닫힘. 새 이벤트 추가 (`.add(Date)`) 모드에서는 버튼을 표시하지 않는다.

## 사전 산출물
- `AddEventDialog` ([13-4](../13-이벤트-다이얼로그-마무리/04-수정모드-타이틀.md)) — `mode: EventDialogMode` 받음.
- `EventDialogMode` — `.add(Date)` / `.edit(Event)` 두 케이스.
- 다이얼로그 호출부 (`ContentView.swift:70`) 가 `onDismiss` 콜백으로 `eventDialog = nil` 처리.

## 작업 가이드

### 1) `.edit` 분기로 삭제 버튼 표시

`AddEventDialog` 의 하단 버튼 영역 (`HStack { 취소 / 저장 }`) 에서, **앞쪽 / 왼쪽** 에 삭제 버튼. `Spacer` 로 좌우 분리하면 자연스럽다:

```swift
HStack(spacing: 13) {
    if case .edit(let event) = mode {
        HoverButton {
            modelContext.delete(event)
            withAnimation(.smooth(duration: 0.3)) {
                onDismiss()
            }
        } label: {
            Text("삭제")
                .foregroundStyle(.white)
                .padding(.vertical, 4)
                .padding(.horizontal, 7)
        }
        .background(Color.red.opacity(0.8))
        .clipShape(RoundedRectangle(cornerRadius: 6))
    }
    Spacer()
    // 기존: 취소 / 저장
}
```

- `if case .edit(let event) = mode` — Swift 의 enum 패턴 매칭으로 `.edit` 일 때만 분기 + 연관값 추출. ([12-04](../12-일-팝업/04-이벤트클릭-수정-프리필완성.md) 에서 같은 결로 다룸.)
- `Spacer()` 가 삭제 (좌) 와 취소/저장 (우) 사이를 밀어냄.
- 색은 `Color.red.opacity(0.8)` 정도. macOS 의 표준 destructive 액션 색에 맞춤.

### 2) 닫힘 흐름

`modelContext.delete(event)` 후 `withAnimation { onDismiss() }` 로 닫는다. `onDismiss` 가 `ContentView` 의 `eventDialog = nil` 을 실행해 다이얼로그가 사라진다.

순서가 중요: **삭제 먼저 → 닫기**. 닫기 먼저 하면 다이얼로그 뷰가 dismiss 되면서 `event` 참조가 무효화될 수 있음.

## 직접 구현하기

- [ ] `Spacer()` 로 삭제와 취소/저장 좌우 분리
- [ ] `modelContext.delete(event)` + `onDismiss()` 순서로 호출
- [ ] `.add` 모드에서는 삭제 버튼이 안 보이는지 확인

## 자가 점검
- 빌드 통과?
- 일 팝업에서 이벤트 클릭 → 수정 다이얼로그 → "삭제" → 다이얼로그 닫힘 + 달력에서 사라짐?
- 새 이벤트 추가 다이얼로그 (`.add` 모드) 에서 삭제 버튼이 안 보이는가?
- 멀티데이도 한 번에 모든 셀/주에서 사라지는가?
- 키보드 단축키 — 현재 취소가 `.cancelAction`(esc), 저장이 `.defaultAction`(enter). 삭제에도 단축키를 줘야 할까? (사용자가 결정. 표준은 `⌘⌫` 인데 디자인 선택.)

## 조금 더 (선택)
- 키보드 단축키 `⌘⌫` (`.keyboardShortcut(.delete, modifiers: .command)`) 를 destructive 버튼에 부착하는 macOS 관용. 학습 가치 있음.
- 삭제 confirmation 을 추가하려면 `.confirmationDialog(_:isPresented:)` 또는 `.alert(_:isPresented:)`. 별도 학습 주제.
