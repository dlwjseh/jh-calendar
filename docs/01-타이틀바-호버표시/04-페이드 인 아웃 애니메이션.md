# 단계 4: 페이드 인/아웃 애니메이션

## 학습 목표
- `isHovered` 상태에 따라 트래픽라이트 버튼의 `alphaValue` 가 0 ↔ 1 사이를 부드럽게 오가게 만든다.
- AppKit 뷰의 애니메이션 방식(`.animator()`) 을 한 번 경험한다.
- "SwiftUI 의 상태 변화 → AppKit 객체로 전달" 이라는 패턴을 익힌다.

## 사전 지식
- 단계 1~3 완료 — 타이틀바 숨김 + 버튼 alphaValue=0 + 좌상단 호버 영역에서 `isHovered` 가 토글됨.
- `Bool` 값이 바뀔 때 어떤 동작을 트리거하는 방법이 SwiftUI 에 여러 개 있다는 것 정도.

## Swift / SwiftUI 개념

### 1) 상태 변화에 반응하기 — `.onChange(of:)`

`isHovered` 가 바뀔 때마다 어떤 코드를 실행하고 싶다면:

```swift
.onChange(of: isHovered) { _, newValue in
    // newValue 는 갱신된 isHovered
}
```

> macOS 14+ / iOS 17+ 의 두 인자 시그니처. 옛 시그니처는 `oldValue` 가 없다. 이 프로젝트는 macOS 14+ 이므로 두 인자 버전을 쓴다.

다른 언어 비유:
- React: `useEffect(() => { ... }, [isHovered])`
- Vue: `watch(isHovered, (n) => { ... })`

### 2) AppKit 뷰의 부드러운 애니메이션 — `.animator()`

SwiftUI 의 `withAnimation { }` 은 SwiftUI 뷰에만 효과가 있다. 우리가 만질 대상은 **NSButton (AppKit)** 이라 다른 길로 가야 한다.

가장 짧은 길: `NSAnimationContext` 로 묶고, 객체에 `.animator()` 프록시를 통해 값을 설정한다.

```swift
import AppKit

NSAnimationContext.runAnimationGroup { ctx in
    ctx.duration = 0.2
    ctx.timingFunction = CAMediaTimingFunction(name: .easeInEaseOut)
    button.animator().alphaValue = 1.0   // 또는 0.0
}
```

핵심:
- `.animator()` 는 "이 변경을 애니메이션화해 줘" 라는 프록시.
- 직접 `button.alphaValue = 1` 로 쓰면 **즉시 점프** 한다 (애니메이션 없음).
- 다른 언어 비유: jQuery 의 `.animate({ opacity: 1 })`, 또는 CSS transition 을 코드로 트리거하는 느낌.

### 3) 코드 정리 — 윈도우와 버튼을 한 번 잡아두기

지금까지 단계 2 의 `.onAppear` 에서 매번 `NSApplication.shared.windows.first` 를 찾았다. 단계 4 에선 **호버가 바뀔 때마다** 도 같은 동작이 필요해진다 → 매번 윈도우를 다시 찾을 수도 있고, 한 번 찾은 버튼들을 변수에 담아둘 수도 있다.

선택지 (어느 쪽이든 OK):

(a) **간단형** — 매번 다시 찾기. 호버는 사용자 동작이라 자주 일어나도 성능 문제 없음.
```swift
private func setTrafficLightAlpha(_ value: CGFloat, animated: Bool) {
    guard let window = NSApplication.shared.windows.first else { return }
    let buttons: [NSButton] = [.closeButton, .miniaturizeButton, .zoomButton]
        .compactMap { window.standardWindowButton($0) }
    if animated {
        NSAnimationContext.runAnimationGroup { ctx in
            ctx.duration = 0.2
            ctx.timingFunction = CAMediaTimingFunction(name: .easeInEaseOut)
            buttons.forEach { $0.animator().alphaValue = value }
        }
    } else {
        buttons.forEach { $0.alphaValue = value }
    }
}
```

(b) **저장형** — `@State private var trafficLightButtons: [NSButton] = []` 로 잡아둔다. 깔끔하지만 `@State` 에 reference 타입을 넣는 것에 대한 주의가 필요 (이번 학습 단계에선 (a) 쪽이 부담이 적다).

이번엔 **(a) 간단형 권장**.

### 4) `guard` 와 `compactMap`

- `guard let x = optional else { return }` — 옵셔널이 nil 이면 함수 탈출. `if let` 의 "조기 탈출" 버전. JS 의 early-return + null check 와 같은 감각.
- `compactMap` — 옵셔널이 섞인 배열에서 nil 을 빼고 풀어낸다. JS 의 `arr.map(...).filter(Boolean)` 합본.

## 구현 가이드

수정할 파일: `JHCalendar/ContentView.swift`.

### 큰 그림

```
struct ContentView: View {
    @State private var isHovered = false

    var body: some View {
        ZStack(alignment: .topLeading) {
            Color.clear.frame(minWidth: 900, minHeight: 600)

            Color.clear
                .frame(width: 100, height: 40)
                .onHover { isHovered = $0 }
        }
        .onAppear {
            // 초기 상태: 즉시 0 으로 (애니메이션 없이)
            setTrafficLightAlpha(0, animated: false)
        }
        .onChange(of: isHovered) { _, hovering in
            // 호버 변화 시: 0/1 로 부드럽게
            setTrafficLightAlpha(hovering ? 1 : 0, animated: true)
        }
    }

    private func setTrafficLightAlpha(_ value: CGFloat, animated: Bool) {
        // TODO: 위에서 본 (a) 간단형 구현
    }
}
```

### 힌트

- `private func` — 이 struct 내부에서만 쓰는 헬퍼.
- `.onChange(of:)` 의 두 인자 시그니처는 macOS 14+ 에서 사용 가능. 만약 deprecation 경고가 뜨면 단일 인자 버전으로 시그니처를 맞춰도 된다.
- 단계 2 의 코드를 헬퍼로 옮기면서 깔끔해질 거다 — **중복 제거**.
- `0.2` 초가 적당. 너무 짧으면 거칠고, 너무 길면 답답하다. 직접 0.15 / 0.2 / 0.3 비교해 보기를 권장.

## 조금 더 (선택)
- `NSAnimationContext.beginGrouping()` / `.endGrouping()` 패턴은 `runAnimationGroup` 의 더 원시적인 버전. 둘 다 같은 기능.
- 호버 영역을 마우스가 빠르게 들락거릴 때 애니메이션이 자연스럽게 이어지는지 관찰해 보기. AppKit 의 implicit animation 은 진행 중인 애니메이션을 부드럽게 takeover 한다.
- 이후 사이드바/툴바를 만들 때, 트래픽라이트와 겹치지 않도록 좌측 패딩을 두는 디자인 결정이 필요해질 거다. 이 기능이 그 출발점이다.
