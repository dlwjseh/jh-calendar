# 단계 1: 기본 타이틀바 숨기기

## 학습 목표
- `Scene` / `WindowGroup` 가 무엇인지 감 잡기.
- `.windowStyle(...)` 한 줄로 macOS 윈도우의 타이틀바를 제거하는 법 익히기.

## 사전 지식
- 현재 코드 상태:
  - `JHCalendarApp.swift` — `@main struct ... : App` 안에 `WindowGroup { ContentView() }` 가 있다.
  - `ContentView.swift` — 빈 `Color.clear` 하나.
- "App / Scene / View" 라는 SwiftUI 의 3단 계층이 있다는 것 정도만 알면 된다.

## Swift / SwiftUI 개념

### 1) `App`, `Scene`, `View` 의 계층

다른 언어/프레임워크와 비교하면:

| 개념 | SwiftUI | 비유 |
|---|---|---|
| 앱 자체 | `App` 프로토콜 (`@main` 붙은 struct) | Java 의 `public static void main(...)` 진입점 |
| 윈도우 단위 | `Scene` (`WindowGroup`, `Window`, `Settings`...) | OS 의 "창" 단위 — 한 앱에 여러 창 |
| 화면 안의 UI | `View` | Vue 의 컴포넌트 (`.vue` 파일) |

`var body: some Scene` 의 `some Scene` 은 "어떤 구체 타입인지는 컴파일러가 추론하지만 `Scene` 프로토콜은 만족한다" 는 뜻 (opaque return type).

> Java 비유: 메서드가 인터페이스 `Scene` 을 반환하는 것과 비슷한 감각. 다만 Java 인터페이스 반환은 호출자도 컴파일러도 구체 타입을 모르는 반면, Swift 의 `some Scene` 은 **컴파일러는 알지만 호출자에겐 감춘다**. 처음엔 그냥 "Scene 을 반환한다" 정도로 읽고 넘어가도 충분하다.

### 2) Modifier 체이닝

SwiftUI 는 모든 게 "원본 + 수식자" 로 표현된다.

```swift
SomeThing()
    .modifierA(...)
    .modifierB(...)
```

Java 의 **Stream API** 가 가장 비슷한 감각이다:

```java
list.stream()
    .filter(...)
    .map(...)
    .collect(...);
```

Stream 의 각 단계가 새로운 Stream 을 반환하듯, SwiftUI modifier 도 **새로운 wrapping View/Scene 타입을 반환** 한다. 즉 순서가 의미를 가진다 (대부분 위→아래로 적용). 빌더 패턴 (`StringBuilder`, `Stream.Builder`) 과도 통하는 발상.

`Scene` 에도 modifier 가 있다. 그 중 하나가 `.windowStyle(...)`.

### 3) `WindowStyle`

macOS 한정으로 윈도우의 chrome (제목줄/배경 등) 종류를 바꿀 수 있다.

- `.automatic` — 기본
- `.titleBar` — 명시적 타이틀바
- `.hiddenTitleBar` — 타이틀바 영역을 콘텐츠 영역으로 흡수
- `.plain` (macOS 13+) — 더 미니멀

이번 단계에선 `.hiddenTitleBar` 만 쓴다.

> 짚고 넘어갈 점: `.hiddenTitleBar` 를 쓰면 트래픽라이트 버튼은 **자동으로 콘텐츠 영역 위에 떠 있는 상태** 가 된다. 다음 단계에서 이걸 직접 숨길 거다.

## 구현 가이드

수정할 파일: `JHCalendar/JHCalendarApp.swift` 한 줄 추가.

골격:

```swift
@main
struct JHCalendarApp: App {
    var body: some Scene {
        WindowGroup {
            ContentView()
        }
        // TODO: 여기에 .windowStyle(...) 추가
    }
}
```

힌트:
- `.windowStyle(...)` 의 인자는 `WindowStyle` 프로토콜을 따르는 값. 정적 멤버 형태로 짧게 쓸 수 있다 (`.something`).
- Xcode 에서 `.windowStyle(.` 까지 쳐보면 자동완성에서 후보가 뜬다 — 거기서 골라보기.
