# 단계 3: 호버 영역과 상태 관리

## 학습 목표
- `@State` 로 SwiftUI 의 가장 기본적인 상태 관리를 익힌다.
- `.onHover { isHovered in ... }` 로 마우스 진입/이탈을 감지한다.
- `ZStack` + `alignment` 로 좌상단에 투명한 호버 영역을 얹는다.

## 사전 지식
- 단계 1, 2 완료 — 타이틀바 사라지고 트래픽라이트 버튼은 평소 안 보이는 상태.
- 단계 2 의 `.onAppear { ... }` 안에서 윈도우/버튼을 만지는 코드가 이미 있다 → 이번 단계에서 이 코드를 살짝 재구성할 수 있다.

## Swift / SwiftUI 개념

### 1) `@State` — SwiftUI 의 가장 작은 상태

```swift
struct ContentView: View {
    @State private var isHovered = false

    var body: some View {
        Text(isHovered ? "ON" : "OFF")
    }
}
```

다른 언어와 비교:

| 프레임워크 | 등가 |
|---|---|
| React | `const [isHovered, setIsHovered] = useState(false)` |
| Vue 3 | `const isHovered = ref(false)` |
| SwiftUI | `@State private var isHovered = false` |

핵심 규칙:
- `@State` 로 선언한 값이 바뀌면 **SwiftUI 가 알아서 body 를 다시 평가** 한다.
- `@State` 는 보통 `private` 으로 — "이 뷰 내부 상태" 라는 신호.
- 직접 할당으로 변경한다: `isHovered = true` (set 함수 따로 없음).

### 2) `.onHover { isHovered in ... }`

마우스 커서가 뷰 영역에 들어오면 `true`, 벗어나면 `false` 가 들어오는 클로저.

```swift
SomeView()
    .onHover { hovering in
        isHovered = hovering
    }
```

웹의 `mouseenter` / `mouseleave` 의 합본이라고 보면 된다.

### 3) `ZStack` 과 `alignment`

`ZStack` 은 자식들을 z 축 (앞뒤) 방향으로 겹쳐 쌓는다.

```swift
ZStack(alignment: .topLeading) {
    Color.clear              // 1. 바닥
    Color.red.frame(...)     // 2. 그 위, 좌상단 정렬
}
```

- `alignment: .topLeading` — 자식들을 좌상단 기준으로 배치.
- 다른 옵션: `.center`, `.bottomTrailing`, `.top`, `.leading` ...
- CSS Grid/Flex 의 정렬 속성과 비슷한 감각.

### 4) "투명하지만 마우스를 받는 영역" 만들기

이 단계에서 우리가 필요한 건:
- 보이지 않음 (배경/내용 없음)
- 그러나 hit-test 는 받는다 (마우스 hover 감지)

→ `Color.clear.frame(width: ..., height: ...)` 가 정확히 이 역할.
`Color.clear` 는 투명한 색이지만 **하나의 View 로서 자기 영역을 가지므로 hover 가 잡힌다**.

## 구현 가이드

수정할 파일: `JHCalendar/ContentView.swift`.

### 큰 그림

```
ZStack(alignment: .topLeading) {
    [기존 콘텐츠 (지금은 그냥 Color.clear + frame)]

    [호버 감지용 투명 영역, 좌상단 100x40]
        .onHover { isHovered = $0 }
}
.onAppear { ... 단계 2 코드 ... }
```

### 골격

```swift
import SwiftUI
import AppKit

struct ContentView: View {
    @State private var isHovered = false   // ← 이 단계에서 추가

    var body: some View {
        ZStack(alignment: .topLeading) {
            // 1) 본 콘텐츠 자리 (지금은 비어있음)
            Color.clear
                .frame(minWidth: 900, minHeight: 600)

            // 2) 호버 감지 영역 (좌상단)
            Color.clear
                .frame(width: 100, height: 40)
                .onHover { hovering in
                    // TODO: isHovered 갱신
                    // TODO: (디버그) 콘솔에 출력해서 hover 가 잡히는지 확인
                }
        }
        .onAppear {
            // 단계 2 의 alphaValue = 0 코드는 그대로 둔다
        }
    }
}
```

### 힌트

- 이 단계에선 **아직 애니메이션이나 alphaValue 변경은 하지 않는다**. `print(...)` 로 호버 진입/이탈이 잘 잡히는지만 확인하는 게 목적.
  ```swift
  .onHover { hovering in
      isHovered = hovering
      print("hover:", hovering)
  }
  ```
- 콘솔은 Xcode 하단 디버그 영역에서 본다 (⌘⇧Y 로 토글).
- 100×40 은 트래픽라이트 3개를 충분히 덮는 크기. 나중에 조정 가능.
