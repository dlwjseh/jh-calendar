# 단계 6: 분(minute) 숫자 입력

> 05 의 시 입력과 **같은 `.onKeyPress` 패턴** 을 분 칸에 적용한다.
> 이 단계는 **새로 배울 Swift/SwiftUI 개념이 없다** (focusable·@FocusState·onKeyPress·클램프 버퍼는 [04](./04-시간입력%20오전오후%20토글.md)·[05](./05-시%20숫자입력.md) 에서 다룸). 그래서 학습 개념 설명 없이 **작업 가이드** 만 둔다. 핵심은 "시와 다른 클램프 규칙" 을 스스로 짚는 것.

## 작업 목표
- `BorderlessTimePicker` 에 분 칸(`[오전/오후][시]:[분]`)을 추가한다.
- 분 입력 규칙을 **시와 다르게** (0~59, 0 정상값, 오전/오후 토글 없음) 구현한다.
- 결과물: ":" 뒤 분 칸 클릭→포커스 후 숫자 입력 시 00~59 로 들어가고, 59 초과면 마지막 숫자만 남는다.

## 사전 지식
- 05 산출물: `JHCalendar/Features/Event/BorderlessTimePicker.swift`
  - `@State hour`, `@State meridiem`, `@FocusState isHourFocused / isMeridiemFocused`
  - 시 칸 `.onKeyPress` 안의 "candidate 클램프 버퍼" 패턴 → 이걸 복제·변형
- 아래는 이미 다뤘으니 **재설명 없이 그대로 적용** (한 줄 링크):
  - `.focusable()` · `.focused($)` · `@FocusState` · 클릭→포커스 · macOS 기본 포커스 링 → [04](./04-시간입력%20오전오후%20토글.md)
  - `.onKeyPress` · `KeyPress.Result(.handled/.ignored)` · 숫자 필터 · `String(format:"%02d",)` → [05](./05-시%20숫자입력.md)

## 구현 가이드
> 정답 풀코드는 제공하지 않는다. 변경 지점 + 규칙 + 시와의 차이만.

### 파일 변경 계획
- `BorderlessTimePicker.swift` 한 파일만 수정.
- 상태 추가: `@State private var minute: Int = 0`, `@FocusState private var isMinuteFocused: Bool`
- 표시: 시와 동일하게 `String(format: "%02d", minute)` (computed property 하나 더, 또는 05 의 `hourFormat` 옆에 `minuteFormat`)
- 레이아웃: 기존 `Text(":")` **뒤에** 분 칸 `Text` 추가. 시 칸과 같은 modifier 묶음(`.focusable()`/`.focused($isMinuteFocused)`/`.onTapGesture`/`.onKeyPress`).

### 분 입력 규칙 — **시와 무엇이 다른지** 가 이 단계의 핵심

숫자 `d`(0~9) 가 들어오면:

1. `candidate = minute * 10 + d`
2. `minute = candidate <= 59 ? candidate : d`  ← 상한이 **12 가 아니라 59**

| | 시 (05) | 분 (이번) |
|---|---|---|
| 상한 | `<= 12` | `<= 59` |
| 0 처리 | 0 되면 `meridiem.toggle()` + 12 | **0 은 정상값** (00 분) — 특수 처리 **없음** |
| 토글 연동 | 있음 | **없음** |

> 즉 분 규칙은 시 규칙에서 **"0 이면 토글+12" 한 줄을 빼고, 상한만 59 로** 바꾼 것이다. 시 코드를 그대로 복붙한 뒤 그 한 줄을 지우려다 **안 지우면 분 0 입력이 깨진다** — 가장 흔한 실수 포인트.

검산 (직접 손으로):
- `minute=0`, `3` → cand 3 ≤59 → `3`. 이어 `0` → cand 30 ≤59 → `30`. 이어 `5` → cand 305 >59 → `5`.
- `5` → 5, `9` → cand 59 ≤59 → `59`.
- `6` → 6, `0` → cand 60 >59 → `0`. ("60" → 0, 마지막 숫자)
- `0` 단독 → cand 0 ≤59 → `0` (00 분, 정상)

### 폴리시 함께 처리 (05 리뷰 메모)
- 05 에서 시 칸 `.padding(.horizontal, 1)` 이 오전/오후 칸(`7`)과 안 맞았다. 이번에 **시·분 칸 padding 을 오전/오후와 같은 값으로 통일** 해서 정렬·클릭 영역을 맞춘다.

### 막힐 만한 지점 — 힌트
- **분 0 입력이 12 로 튀거나 오전/오후가 바뀐다** — 시 코드를 복사하며 `if newMinute == 0 { ... }` 를 안 지웠을 가능성. 분엔 그 분기 자체가 없어야 한다.
- **상한을 12 그대로 둠** — `<= 12` 를 `<= 59` 로 바꿨는지 확인.
- **Tab 이동이 분 칸에서 안 먹음** — 05 와 동일 원인: 숫자 외 키에서 `.handled` 반환하면 안 됨. 숫자만 `.handled`, 그 외 `.ignored`.
- **`Text(":")` 위치** — 분 칸은 콜론 *뒤* 다. HStack 순서가 `[오전/오후][시][:][분]` 인지 확인.
