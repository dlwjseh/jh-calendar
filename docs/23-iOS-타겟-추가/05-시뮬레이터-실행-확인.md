# 단계 5: 시뮬레이터 실행 확인 + 회고

## 작업 목표
> 새 Swift/SwiftUI 개념 없음. **실행/검증/회고** 단계.

iOS 타겟이 다양한 디바이스 크기에서 깨지지 않고 동작하는지 확인하고, (선택적으로) 본인 iPhone 에 설치해본다.

## 사전 지식
- 단계 01~04 완료 (월간 캘린더 표시까지)

## 작업 가이드

### 1. Run Destination 여러 개 시도
Xcode 상단 디바이스 드롭다운에서 **여러 시뮬레이터**를 바꿔가며 ⌘R:
- iPhone 16 (표준)
- iPhone 16 Pro Max (큰 화면)
- iPhone SE 3rd gen (작은 화면)
- iPad Pro 13-inch (가로 폭 매우 넓음 — 깨질 수도 있음)

체크 포인트:
- 그리드가 화면을 꽉 채우는가, 빈 여백이 어색하지 않은가?
- 작은 화면(SE) 에서 날짜 숫자가 잘리지 않는가?
- iPad 에서 셀이 너무 커지면 → iPad 대응은 별도 작업으로 미룸 (지금 학습 범위 밖)

### 2. 다크 모드 확인
시뮬레이터 메뉴 → **Features > Toggle Appearance** (또는 ⌘⇧A).
- 22 단계의 다크 테마가 그대로 적용되어야 함.
- 색이 어색한 곳이 있으면 기록만 해두고 → 별도 단계로 처리.

### 3. SwiftData 영속화 확인 (선택)
임시 시드로 이벤트 하나 추가 → 앱 종료(시뮬레이터 홈으로) → 다시 켜면 그대로 있는지.
- 그대로 있으면 SwiftData 컨테이너가 정상.
- 없어지면 modelContainer 설정 다시 확인.

### 4. (선택) 실기기에 설치
**무료 Apple ID 로도 가능** (7일짜리 임시 서명):
1. Xcode > Settings > Accounts → Apple ID 추가
2. iOS 타겟 → Signing & Capabilities → Team 선택 (Personal Team)
3. iPhone 을 USB / 동일 Wi-Fi 로 연결, 디바이스 신뢰 허용
4. Run Destination 에서 본인 디바이스 선택 → ⌘R
5. iPhone 에서 **설정 > 일반 > VPN 및 기기 관리** → 개발자 앱 신뢰

> 유료 개발자 계정이 없으면 7일 후 앱이 만료된다. 학습용으론 충분.
> 처음엔 잘 안 되는 경우가 많음 — 안 되면 시뮬레이터까지만 하고 넘어가도 OK.

### 5. macOS 회귀 최종 확인
스킴을 `JHCalendar` (macOS) 로 → ⌘R → 기존 동작 그대로인지.
