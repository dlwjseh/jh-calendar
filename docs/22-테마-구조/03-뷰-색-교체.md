# 단계 3: 뷰 색 교체

> 새로 배울 Swift/SwiftUI 문법이 없는 단계(01·02의 조합 적용)라 **작업 가이드**만 둔다.

## 작업 목표
하드코딩된 크롬 색을 전부 `theme.<슬롯>`으로 바꾼다. `.classic`이므로 **화면은 그대로 보여야 정상** — "보이는 변화 없음"이 곧 "배선 성공"이다.

## 준비
색을 읽는 각 뷰 맨 위에 추가:
```swift
@Environment(\.calendarTheme) private var theme
```

## 파일별 교체 맵

### `Views/MonthlyCalendar/DayCellView.swift`
- `textColor` computed:
  - `isToday` → `theme.todayText`
  - `!cell.isInCurrentMonth` → `theme.subtleText`
  - `isHoliday` → `theme.sunday`  *(공휴일 숫자는 일요일과 같은 빨강)*
  - weekday `case 1` → `theme.sunday`, `case 7` → `theme.saturday`, `default` → `theme.weekdayText`
- 오늘 동그라미 `Circle().fill(.red)` → `theme.todayFill`
- 공휴일 이름 `.foregroundStyle(Color.holiday)` → `theme.holiday`
- 그리드 `.stroke(Color.gray.opacity(0.2), …)` → `theme.gridLine`

### `Views/MonthlyCalendar/MonthlyCalendarView.swift`
- `headerColor(at:)`: `case 0` → `theme.sunday`, `case 6` → `theme.saturday`, `default` → `theme.subtleText`

### `Views/Holiday/HolidayPopupRow.swift`
- `.fill(Color.holiday)` / `.foregroundStyle(Color.holiday)` → `theme.holiday`

### (선택) 그 외
- 저장 버튼 `Color.accentColor`(AddEventDialog) → `theme.accent` — 원하면.
- 멀티데이/팝업의 `.white`, 배경/그림자/호버는 **이번 범위 밖**(README 참고). 손대지 말 것.

## 주의
- **`category.color` / `event.color` / `e.color` 는 절대 건드리지 않는다** (사용자 카테고리 색).
- `textColor` 처럼 **computed property 안에서** `theme`를 읽어도 된다 — `@Environment` 프로퍼티는 뷰 인스턴스에 저장돼 있어 같은 struct 안 어디서든 접근 가능.
- `Color.holiday` static 을 모든 뷰에서 떼어낸 뒤에는, `Shared/Models/HolidayModels.swift` 의 `static let holiday` 를 **제거**해 출처를 테마 하나로 통일. (제거 후 빌드해서 잔여 참조 없는지 확인)
