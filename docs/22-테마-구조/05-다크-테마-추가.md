# 단계 5: 다크 테마 추가 (첫 테마 적용 사례)

> 04에서 "테마 추가 = 연결점 3곳" 골격을 만들었고, 이 문서는 그 위에 **실제 첫 테마(dark)** 를 얹은 기록이다.
> 학습 힌트 문서가 아니라 **구현·설계 결정 기록**.

## 무엇을 했나
- `CalendarTheme.dark` 추가 (강조색을 어두운 배경용으로 밝게 튜닝)
- 플로팅 툴바에 **라이트/다크 토글 버튼**(달/해 아이콘) 추가 — `@AppStorage("selectedThemeId")` 직접 토글
- 앱 전체(사이드바·다이얼로그·머티리얼 포함)가 한 번에 전환

## 핵심 설계 결정

### 1. 배경 슬롯 확장 ❌ → `preferredColorScheme` ✅
처음엔 "배경/표면 색 슬롯(`background`/`surface` 등)을 테마에 추가" 방향을 고려했으나 폐기.
- **문제:** 메인 캘린더만 칠하면 사이드바 글자(`.primary`=검정)가 어두운 패널 위에 묻히고, 다이얼로그·툴바 머티리얼은 라이트로 남아 **반쪽짜리**. 모든 표면/글자색을 일일이 테마화해야 해서 슬롯이 폭발.
- **채택:** `CalendarTheme`에 `colorScheme: ColorScheme?` 슬롯 **하나만** 추가하고, 루트에서 `.preferredColorScheme(theme.colorScheme)` 적용.
  - SwiftUI가 `.primary`/`.secondary`/`.background`/머티리얼/윈도우 배경을 **자동으로 다크 팔레트로** 전환 → 사이드바·다이얼로그까지 공짜.
  - 22 README의 "배경은 라이트/다크 자동대응" 철학과 일치.
- 테마는 강조색(일/토/오늘/공휴일/그리드/accent)만 정의하면 됨.

### 2. classic = `.light` 명시 (nil 금지)
- 초기엔 `classic.colorScheme = nil`(시스템 따름)으로 뒀더니, **classic → dark → classic 왕복 후 평일 숫자/헤더가 사라지는** 버그 발생.
- **원인:** macOS SwiftUI에서 `preferredColorScheme`를 런타임에 `.dark` → `nil`로 되돌리면, 윈도우 배경은 라이트로 가지만 뷰 트리의 `colorScheme` 환경값이 **다크로 stale**하게 남는 desync. → 배경 흰색 + `.primary` 글자 흰색 = 흰 배경에 묻힘(색 박힌 일/토/공휴일만 보임).
- **해결:** classic도 `.light`로 **명시**. `.light` ↔ `.dark` 두 명시값 사이 토글은 desync 없음.
- **트레이드오프:** 이제 classic은 OS가 다크여도 라이트 고정(= "테마는 사용자 명시 선택" 모델). "시스템 따름"이 필요하면 별도 3번째 옵션으로 추가해야 함(미구현).

## 실제 변경 (파일별)
- `Shared/Theme/Theme.swift` — `colorScheme` 슬롯 추가, `classic.colorScheme = .light`, `static let dark`, `resolveTheme`에 `case "dark"`
- `JHCalendarApp.swift` — `let theme = resolveTheme(themeId)` 후 `.preferredColorScheme(theme.colorScheme)`
- `Views/FloatingToolbar/FloatingToolbar.swift` — `@AppStorage("selectedThemeId")` + 달/해 토글 버튼
- `Views/Event/DayPopupDialog.swift` — 팝업 카드 `.background(.white)` → `.background(.background)` (리터럴 흰색은 다크에서 안 바뀌어 글자가 묻히던 잠재버그 동시 수정)

## 알려진 한계 / 추후
- 토글이 **라이트↔다크 2개 전용** — 테마가 3개 이상이면 토글을 `Picker`/`Menu`로 교체 필요.
- **"시스템 따름" 옵션 없음** (desync 회피 위해 명시값만 사용).
- 다이얼로그 보더/필드배경 `gray.opacity` 등은 `colorScheme`로 자동 대응되므로 별도 슬롯 불필요.
- 일 팝업 **날짜 제목은 `.white` 고정**이라 라이트에서 흐릿할 수 있음(기존 동작 유지 — 거슬리면 테마 텍스트로 정리 가능).
