# 단계 4: 종일 이벤트 바 렌더링

> 새로 배우는 Swift/SwiftUI 문법이 없다(이미 다룬 View 조합·`@Binding`/파라미터 전달·Color hex·`RoundedRectangle` 류 조합). 그래서 개념 설명 대신 **작업 가이드**만 둔다.

## 작업 목표
`DayCellView` 가 `cell` 외에 **그 날의 이벤트 배열**을 받아, 그 중 **종일 이벤트**를 카테고리 색 바(bar) 안에 이벤트명으로 그린다. (시간 지정은 05.)

## 사전 산출물
- 03 의 `eventsByDay(_:)` 인덱스 (`MonthlyCalendarView` 에 파생 프로퍼티 존재)
- `DayCellView` 현재: `let cell: DayCell` 만 받음, 날짜 숫자만 그림
- `Category.color: Color` (hex 변환, `04-사이드바-카테고리-UI` / `ColorHex.swift`)

## 작업 가이드

**1) 셀에 데이터 주입 — 셀은 "멍청하게"**

```swift
struct DayCellView: View {
    let cell: DayCell
    let events: [Event]        // TODO: 추가. 셀은 필터 안 함, 받은 것만 그림
}
```
`MonthlyCalendarView` 의 `ForEach(row) { cell in ... }` 에서:
```swift
DayCellView(cell: cell,
            events: eventsByDayIndex[Calendar.current.startOfDay(for: cell.date)] ?? [])
// 키 생성 규칙이 03 인덱스와 '동일' 해야 함 (startOfDay)
```
> 키 정규화를 한 곳에서 재사용하려면 작은 헬퍼(`func dayKey(_:) -> Date`)를 만들어 인덱스 생성·조회가 같은 함수를 쓰게 하라. (03 의 흔한 버그 방지.)

**2) 종일 바 그리기**

- `events` 에서 `isAllDay == true` 만 추린다.
- 각 종일 이벤트 = 가로로 꽉 찬 둥근 사각형 바:
  - 배경: `event.category?.color ?? .gray`
  - 안에 `Text(event.name)` — 작게, 한 줄, 넘치면 말줄임:
    - `.lineLimit(1)`, `.truncationMode(.tail)`, 필요시 `.minimumScaleFactor(...)`
  - 글자색은 배경 대비 고려 (일단 `.white` 로 시작해도 됨 — 대비 자동화는 과설계, 나중에)
- 기존 날짜 숫자 아래(`Spacer` 자리)에 `VStack(spacing: 2)` 로 바들을 쌓는다.

```swift
VStack(spacing: 0) {
    Text("\(cell.day)") ... // 기존 유지

    VStack(spacing: 2) {
        ForEach(allDayEvents) { e in
            Text(e.name)
                .font(.system(size: 10))
                .lineLimit(1)
                .frame(maxWidth: .infinity, alignment: .leading)
                .padding(.horizontal, 4).padding(.vertical, 1)
                .background(/* TODO: 카테고리 색 바, RoundedRectangle */)
        }
    }
    Spacer(minLength: 0)
}
```
- `ForEach(allDayEvents)` — `Event` 가 `@Model` 이라 `Identifiable` 충족(PersistentIdentifier). 그대로 `ForEach` 가능. 안 되면 `id: \.persistentModelID`.

**3) 현 단계 한정**
- 단일 일 종일만. 멀티데이 종일(여러 칸 가로지르는 연속 바)은 06 로 미룬다 — 지금은 각 날 칸 안에서 독립 바로 충분.

## 직접 구현하기
- [x] `DayCellView` 에 `events: [Event]` 파라미터 추가
- [x] 호출부에서 인덱스로 슬라이스 주입 (키 규칙 = 03 과 동일)
- [x] 종일 이벤트만 필터 → 카테고리 색 바 + 이벤트명
- [x] 말줄임/폰트로 좁은 셀에서 깨지지 않게

> 다 끝나면 "다 했어" 라고 알리면 리뷰.

## Claude 리뷰 체크리스트
- [x] 셀이 필터/조회 로직을 갖지 않음 (멍청한 셀 유지 — 날짜 필터는 부모, 종류 필터만 셀)
- [x] 인덱스 키 생성 규칙이 03 과 동일 (생성·조회 모두 동일 `calendar` 인스턴스의 `startOfDay`)
- [x] 카테고리 색·말줄임 등 레이아웃이 좁은 셀에서 견고 (`lineLimit(1)` + 말줄임)
