# 단계 1: 이벤트 날짜 필드 영속화

## 학습 목표
`Event` @Model 에 `startDate` / `endDate` 를 추가하고, `AddEventDialog` 의 `@State startDate/endDate` 를 실제 저장/편집에 반영한다. (이번 기능의 토대 — 날짜가 없으면 셀에 그릴 수 없다.)

> 이 단계는 `10-이벤트-추가-다이얼로그` README 의 "후속 예정: startDate/endDate 영속화 / isSaveEnabled 정상화" 를 닫는 작업이기도 하다.

## 사전 지식
- `Event` @Model 현재 정의: `name`, `isAllDay`, `category?` (날짜 필드 없음)
- `AddEventDialog` 에 이미 `@State startDate`, `@State endDate`, `mode(.add/.edit)`, `modelContext` 가 있음
- SwiftData `@Model` / `modelContext.insert` → `09`, `10` 참고

## Swift / SwiftUI 개념
이 단계의 **새 측면**: SwiftData 모델에 **필드를 추가하면 저장소 스키마가 바뀐다.**

- 기본값/옵셔널이 있는 단순 필드 추가는 SwiftData 가 **lightweight migration** 으로 자동 처리한다. (Spring 으로 치면 컬럼 추가 후 Hibernate `ddl-auto=update` 가 알아서 컬럼 만들어 주는 느낌. 단, 자동으로 안 되는 변경도 있으니 "필드 추가" 정도만 안전하다고 알아 둘 것.)
- 그래도 개발 중 스키마가 꼬이면 가장 확실한 초기화는 **앱 데이터 삭제**:
  - 시뮬레이터/앱 데이터 위치의 `.store` 파일 삭제, 또는 개발 단계에선 그냥 기존 DB 날리고 새로 시작.
- `Date` 는 그대로 저장 가능한 타입이라 별도 변환 불필요.

## 구현 가이드
> 정답 풀코드는 제공하지 않는다.

**1) `EventModels.swift` — 필드 추가**

```swift
@Model
final class Event {
    var name: String
    var isAllDay: Bool
    var startDate: Date     // TODO: 추가
    var endDate: Date       // TODO: 추가  (단일 일도 end 저장 → 멀티데이 대비)
    var category: Category?

    init(name: String, isAllDay: Bool,
         startDate: Date, endDate: Date,     // TODO: init 시그니처 갱신
         category: Category? = nil) {
        // TODO: self.* 대입
    }
}
```

- 단일 일 일정이라도 `endDate` 를 저장한다. 지금은 보통 `startDate` 와 같은 날이지만, 필드를 미리 둬야 03·04 의 인덱스/렌더 설계가 멀티데이까지 흔들림 없이 확장된다. (memory: 멀티데이까지 생각한 설계)

**2) `AddEventDialog.swift` — 저장/편집 연동**

- `.add`: `Event(name:isAllDay:startDate:endDate:category:)` 생성 시 `@State startDate/endDate` 를 넘긴다.
- `.edit(event)`: `onAppear`(또는 mode 해석 지점)에서 기존 `event.startDate/endDate` 를 `@State` 로 끌어와 폼을 채우고, 저장 시 다시 대입.
- **`isAllDay == true`** 면 시간 의미가 없으니 저장 직전에 날짜를 정규화하는 걸 권장:
  - `startDate = Calendar.current.startOfDay(for: startDate)` 같은 식. (정규화를 여기서 할지 03 인덱스에서 할지는 04 에서 다시 언급 — 일단 "종일은 시각이 의미 없다" 만 기억.)

**3) `isSaveEnabled` 정상화**

- 현재 항상 `false`. 최소 조건으로 바꾼다: 이벤트명 trim 후 비어있지 않음 + (필요시) `endDate >= startDate`.

```swift
private var isSaveEnabled: Bool {
    !name.trimmingCharacters(in: .whitespaces).isEmpty
    && endDate >= startDate          // TODO: 조건 확정
}
```
