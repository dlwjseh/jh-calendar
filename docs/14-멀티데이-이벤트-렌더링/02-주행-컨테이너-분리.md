# 단계 2: 주(week) 행 컨테이너로 분리 (리팩토링)

> 새 개념 없음. 다음 단계의 `GeometryReader` 와 멀티데이 overlay 가 **주(week) 단위로 묶인 자체 View** 위에 올라가야 하므로, 지금의 `HStack { ForEach(row) }` 한 줄을 별도 View 로 추출만 한다.

## 작업 목표
[`MonthlyCalendarView`](../../JHCalendar/Features/MonthlyCalendar/MonthlyCalendarView.swift) 의 일 그리드에서 한 주를 그리는 부분을 **`WeekRowView`** 로 추출한다. 시각/동작은 동일.

## 사전 산출물
- `MonthlyCalendarView` 본문에 다음 구조가 있다:
  ```swift
  ForEach(store.rows, id: \.first?.id) { row in
      HStack(spacing: 0) {
          ForEach(row) { cell in
              DayCellView(cell: cell, events: ...) { ... }
          }
      }
      .frame(maxHeight: .infinity)
  }
  ```
  → 이 `HStack { ... }` 통째로 새 View 로 옮기는 게 목표.

## 작업 가이드

**1) 새 파일 `WeekRowView.swift` 생성**

`JHCalendar/Features/MonthlyCalendar/WeekRowView.swift` 에 새 파일. `MonthlyCalendar` 폴더는 **sync group** 으로 등록돼 있으므로 (CLAUDE.md 참고) 파일만 두면 Xcode 가 자동 인식. pbxproj 편집 불필요.

```swift
import SwiftUI

struct WeekRowView: View {
    let row: [DayCell]
    let eventsByDayIndex: [Date: [Event]]
    let onSelectDay: (Date) -> Void

    // TODO: Calendar 인스턴스가 필요하면 같이 받거나, 안에서 Calendar.current
    private let cal = Calendar.current

    var body: some View {
        HStack(spacing: 0) {
            ForEach(row) { cell in
                DayCellView(cell: cell,
                            events: eventsByDayIndex[cal.startOfDay(for: cell.date)] ?? [],
                            onSelectDay: onSelectDay)
            }
        }
    }
}
```

- 부모(`MonthlyCalendarView`) 가 들고 있는 **세 가지**(주 셀 배열, 인덱스, 셀 탭 콜백) 를 그대로 받는다.
- `cal` 은 인스턴스 안에서 `Calendar.current` 로 만들어도 OK (다른 곳도 그렇게 쓴다).

**2) `MonthlyCalendarView` 호출부 교체**

```swift
ForEach(store.rows, id: \.first?.id) { row in
    WeekRowView(row: row,
                eventsByDayIndex: eventsByDayIndex,
                onSelectDay: { date in
                    withAnimation(.smooth(duration: 0.3)) {
                        dayPopup = date
                    }
                })
    .frame(maxHeight: .infinity)
}
```

- `withAnimation` 같은 부모의 책임(팝업 열기 애니메이션) 은 부모에 그대로 두고, `WeekRowView` 는 그저 "셀 선택됐다" 만 전달.

**3) 빌드 + 시각 동일 확인**

추출 자체는 행위를 안 바꾸므로 화면이 그대로여야 정상. 다르게 보이면 어딘가 props 누락.
