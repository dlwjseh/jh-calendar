# 단계 11: 좌/우 끝 모서리 캡

## 학습 목표
- 도형의 **일부 모서리만** 둥글게 만드는 두 가지 방법 (`UnevenRoundedRectangle` vs 부분 corner masking) 을 안다.
- 토막난 멀티데이 바가 **시작 토막은 왼쪽만**, **끝 토막은 오른쪽만**, **중간 토막은 평평** 하게 보이도록 분기.

## 사전 지식
- 07 단계의 슬라이스가 `(event, interval)` 형태 — 원본 `event.startDate` / `event.endDate` 와 `interval.start` / `interval.end` 비교로 "첫 토막" / "마지막 토막" 판정 가능.

## Swift / SwiftUI 개념

### `UnevenRoundedRectangle` (macOS 13+ / iOS 16+)

각 모서리에 **독립적인 radius** 를 줄 수 있는 도형.

```swift
UnevenRoundedRectangle(topLeadingRadius: 3,
                       bottomLeadingRadius: 3,
                       bottomTrailingRadius: 0,
                       topTrailingRadius: 0)
    .fill(event.color)
```

> SwiftUI 의 `RoundedRectangle` 은 모든 모서리에 같은 radius 만 적용 가능. `UnevenRoundedRectangle` 이 1대1로 분기를 받음. CSS `border-radius: 3px 0 0 3px` 와 같은 결.

대안 — `RoundedRectangle` + `.clipShape`/마스킹 콤보도 있지만, 이번엔 `UnevenRoundedRectangle` 한 줄이 가장 깔끔.

### "첫 토막" / "마지막 토막" 판정

`slice.interval.start == event.startDate` (또는 `startOfDay` 기준 비교) 면 첫 토막. 마찬가지로 `slice.interval.end >= event.endDate` 면 마지막 토막.

```swift
private func cornerCaps(for slice: LanedSlice) -> (leading: Bool, trailing: Bool) {
    let cal = Calendar.current
    let isFirst = cal.isDate(slice.interval.start, equalTo: slice.event.startDate, toGranularity: .day)
    let isLast  = cal.isDate(cal.date(byAdding: .second, value: -1, to: slice.interval.end) ?? slice.interval.end,
                             equalTo: slice.event.endDate,
                             toGranularity: .day)
    return (leading: isFirst, trailing: isLast)
}
```

- `isDate(_,equalTo:,toGranularity:.day)` 로 "같은 날" 비교 → [Calendar-와-Date 3-7](../자주-쓰는-기술들/Calendar-와-Date.md)
- `interval.end` 가 자정 보정된 점을 07 에서 다뤘듯, 여기서도 `-1초` 통과시켜 비교.

## 구현 가이드

**1) 배경 도형 교체**

06 단계의 `.background(RoundedRectangle(cornerRadius: 3).fill(event.color))` 를 분기로:

```swift
let caps = cornerCaps(for: laned)

.background(
    UnevenRoundedRectangle(
        topLeadingRadius:     caps.leading  ? 3 : 0,
        bottomLeadingRadius:  caps.leading  ? 3 : 0,
        bottomTrailingRadius: caps.trailing ? 3 : 0,
        topTrailingRadius:    caps.trailing ? 3 : 0
    )
    .fill(laned.event.color)
)
```

**2) 시각 확인 시나리오**

- 5월 18일(일) ~ 5월 24일(토) — 한 주 안. **양쪽 캡** (둥글 둥글).
- 5월 18일(일) ~ 5월 26일(월) — 첫째 주: 좌측 둥글, 우측 평평 / 둘째 주: 좌측 평평, 우측 둥글.
- 5월 18일(일) ~ 6월 3일(수) — 3주 걸침. 첫째 주: 좌측 둥글 / 가운데 주: 양쪽 평평 / 마지막 주: 우측 둥글.

평평한 변이 다음 주 시작과 시각적으로 이어져 보이는 게 이번 단계의 핵심.
