# 단계 12: 일 팝업에 걸쳐있는 멀티데이 포함

> 새 개념 없음. 이미 배운 스킬 조합.

## 작업 목표
- 일 팝업이 **그 날에 시작하는 이벤트** 만이 아니라 **그 날에 걸쳐있는 멀티데이** 까지 보여준다.
- 시간 표시는 **시작일 팝업에만**. 걸쳐있는 날 팝업에서는 시간 자리 비움 (종일 이벤트와 동일 처리).
- 멀티데이의 "기간" 같은 별도 표시는 하지 않는다.

## 사전 산출물
- `DayPopupDialog` — `init` 안에서 `@Query` 를 동적으로 구성. ([12-02](../12-일-팝업/02-일클릭-팝업-모달.md))
- `DayPopupEventRow` — `event.isAllDay` 분기로 시간 표시.
- `eventsByDay` 의 멀티데이 day 순회 패턴 ([14-01](./01-eventsByDay-멀티데이-확장.md)).

## 변경할 두 곳

### 1) `DayPopupDialog` 의 `@Query` predicate

현재:

```swift
filter: #Predicate<Event> { event in
    event.startDate >= dayStart && event.startDate < dayEnd
}
```

→ "그 날에 **시작** 하는 이벤트". 멀티데이가 걸쳐있는 날은 누락.

바꿔야 할 의미: "이벤트 인터벌이 그 날 인터벌과 **겹치는** 이벤트".

두 인터벌 `[aStart, aEnd]` 와 `[bStart, bEnd)` 가 겹치는 표준 조건:

```
aStart < bEnd  AND  aEnd >= bStart
```

→ 적용:

```swift
filter: #Predicate<Event> { event in
    event.startDate < dayEnd && event.endDate >= dayStart
}
```

**왜 `>=` 인가** — 종일 이벤트는 `AddEventDialog` 가 저장 직전에 `endDate = startOfDay(endDate)` 로 정규화한다(`AddEventDialog.swift:150`). 즉 5/26 까지인 종일 멀티데이는 `endDate == 5/26 00:00` 으로 저장된다. 5/26 팝업(`dayStart = 5/26 00:00`)에서 `endDate >= dayStart` → `5/26 == 5/26` → true. `>` 였다면 false 가 되어 마지막 날이 빠진다. 14-7 의 "DateInterval end 의미 분기" 와 같은 결의 함정.

> `#Predicate` 안에서 `Calendar.startOfDay(...)` 같은 함수 호출 못 한다는 한계는 [12-02 3) 항목](../12-일-팝업/02-일클릭-팝업-모달.md)에서 다룸. 미리 계산한 `dayStart` / `dayEnd` 를 단순 비교만 하는 패턴은 그대로 유지.

### 2) `DayPopupEventRow` 의 시간 표시 분기

지금 조건:

```swift
if !event.isAllDay {
    Text(event.startDate, format: .dateTime.hour().minute())
        ...
}
```

→ 시간 지정 이벤트면 무조건 시작 시각 표시. 시간 지정 멀티데이가 걸쳐있는 날(예: 5/22) 에서도 `5/20 10:00` 의 시각이 그대로 표시되어 혼란.

바꿀 규칙: **그 날이 이벤트의 시작일일 때만** 시간 표시. 그러려면 row 가 "어느 날의 팝업인지" 를 알아야 한다 → `date: Date` prop 추가.

```swift
struct DayPopupEventRow: View {
    let event: Event
    let date: Date                    // 추가
    var onClick: (Event) -> Void

    private var showsTime: Bool {
        !event.isAllDay
            && Calendar.current.isDate(event.startDate, inSameDayAs: date)
    }

    var body: some View {
        HStack(spacing: 10) {
            // ...
            if showsTime {
                Text(event.startDate, format: .dateTime.hour().minute())
                    ...
            }
        }
    }
}
```

호출부 (`DayPopupDialog`) 도 `date: date` 전달.

> `isDate(_,inSameDayAs:)` 는 `isDate(_,equalTo:,toGranularity:.day)` 의 축약형 — 14-11 의 `cornerCaps` 비교와 같은 결.

## 구현 가이드 (요약)

1. `DayPopupDialog.init` 의 `#Predicate` 두 조건을 `startDate < dayEnd && endDate >= dayStart` 로 교체.
2. `DayPopupEventRow` 에 `let date: Date` 추가, `showsTime` 계산 분기 → 시간 `Text` 감싸기.
3. 호출부에서 `DayPopupEventRow(event: event, date: date, onClick: onSelectEvent)`.

## Claude 리뷰 체크리스트
- [ ] predicate 가 두 인터벌 겹침 조건 (`startDate < dayEnd && endDate >= dayStart`)
- [ ] `endDate >= dayStart` (`>` 가 아닌 `>=`) — 종일 멀티데이 마지막 날 케이스
- [ ] 시간 표시는 `event.isAllDay == false && 시작일 == 팝업 날짜` 둘 다 만족할 때만
- [ ] `DayPopupEventRow` 가 `date` prop 을 호출부로부터 받음 (자체 `Date()` 계산 X)
