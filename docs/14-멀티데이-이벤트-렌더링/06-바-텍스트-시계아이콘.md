# 단계 6: 멀티데이 바 안 텍스트 + 시간지정 시계 아이콘

> 새 개념 거의 없음. 작은 SF Symbol 표시 → [02-02 버튼과 SF Symbols](../02-상단-플로팅-툴바/02-버튼과%20SF%20Symbols.md) 와 같은 패턴.
> 단색 직사각형이었던 멀티데이 바 안에 **이벤트명** + (시간지정이면) **`clock` 아이콘**.

## 작업 목표
04 의 `RoundedRectangle.fill(event.color)` 를 **컨텐츠가 있는 컨테이너** 로 바꾼다.

- 종일 멀티데이: 흰색 텍스트 (이벤트명)
- 시간지정 멀티데이: 같은 바에 작은 `clock` 아이콘을 텍스트 앞에 prepend (`event.isAllDay == false` 분기)

## 사전 산출물
- 04 단계의 단색 바가 잘 그려진다.

## 작업 가이드

**1) 단색 fill 을 컨텐츠 + 배경 구조로**

```swift
HStack(spacing: 3) {
    if !event.isAllDay {
        Image(systemName: "clock")
            .imageScale(.small)         // 작은 크기
            .font(.system(size: 9))     // 조금 더 보수적으로 크기 줄임
    }
    Text(event.name)
        .font(.system(size: 11))
        .lineLimit(1)
    Spacer(minLength: 0)                // 왼쪽 정렬
}
.foregroundStyle(.white)                // 카테고리 색 배경 위 텍스트 대비
.padding(.horizontal, 6)
.frame(width: f.width, height: 16, alignment: .leading)
.background(RoundedRectangle(cornerRadius: 3).fill(event.color))
.offset(x: f.x, y: 24)
```

- **순서가 핵심**: `.padding` → `.frame(width:)` → `.background` 순. `.frame(width:)` 다음에 `.background` 가 와야 배경이 그 너비에 정확히 맞춰진다.
- **`Spacer(minLength: 0)`** — 이름이 짧을 때 가운데가 아닌 왼쪽 정렬을 강제. 다른 곳에서도 자주 쓰는 트릭.
- **`.foregroundStyle(.white)`** — `Image` + `Text` 둘 다 흰색으로 한 번에 칠하기.

> `.foregroundStyle(.white)` 가 자식들 색을 다 바꾼다. SF Symbol 도 단색 모드면 함께 흰색. (Hierarchical / Palette / Multicolor symbol 은 다른 룰이지만 `clock` 은 단순 monochrome 이라 OK.)

**2) 시간지정 시계 아이콘 — 크기 / 굵기**

`clock` SF Symbol 은 기본적으로 폰트 메트릭을 따른다. 옵션:

```swift
Image(systemName: "clock")
    .imageScale(.small)              // 텍스트 폰트 대비 약간 작게
    .font(.system(size: 9, weight: .semibold))   // 또는 폰트 크기 직접
```

- 너무 가늘면 멀티데이 색 위에서 안 보임 → `.semibold` 정도.
- 더 작은 아이콘이 마음에 들면 다른 후보:
  - `clock.fill` (살짝 더 진함)
  - `circle.dotted` 같은 추상적 시간 표시
  - 처음 시도는 `clock` 으로 두고 다른 게 더 좋아 보이면 교체

**3) 텍스트가 바 너비를 넘으면**

`lineLimit(1)` + 자동 truncation 으로 충분. 단계 11 캡 처리 후에도 자연스럽게 잘림.
