# 단계 7: 주 경계 토막 (`DateInterval` 교집합)

## 학습 목표
멀티데이 이벤트가 **두 주 이상**에 걸치면, 각 주의 행에서 그 주에 해당하는 **자기 구간만** 그린다.

## 사전 지식
- `DateInterval`, `intersects(_:)` 의 기본 → [Calendar-와-Date.md 6장](../자주-쓰는-기술들/Calendar-와-Date.md)
- 03 의 `multidayEvents(in: weekInterval, from:)` 함수가 이미 "이 주에 걸친 이벤트들" 까지는 골라줌. 골라진 이벤트의 `startDate`/`endDate` 가 주 바깥일 수 있다는 게 이번 문제.

## Swift / SwiftUI 개념

### `DateInterval.intersection(_:)` — `intersects` 와 다른 점

| 메서드 | 반환 | 의미 |
|---|---|---|
| `a.intersects(b)` | `Bool` | 겹치는가 |
| `a.intersection(with: b)` | `DateInterval?` | **겹치는 부분의 새 DateInterval** (안 겹치면 nil) |

이번에 쓰는 건 후자.

```swift
let weekInterval = cal.dateInterval(of: .weekOfYear, for: row.first!.date)!
let eventInterval = DateInterval(start: event.startDate, end: event.endDate)
let drawInterval = eventInterval.intersection(with: weekInterval)
// drawInterval?.start, drawInterval?.end 가 "이 주에서 그릴 시작/끝"
```

> Java 라면 `Range.intersection(other)` / `Interval.overlap(other)` 같은 결. 두 구간의 교집합을 명시적 값으로.

### 토막 후 화면 좌표 다시 계산

04 단계의 `barFrame(for:weekStart:rowWidth:)` 는 `event.startDate` / `event.endDate` 를 직접 썼다. 이제 그 자리에 **토막난 interval 의 start/end** 를 넣는다.

```swift
private func barFrame(for slice: (event: Event, interval: DateInterval),
                      weekStart: Date,
                      rowWidth: CGFloat) -> (x: CGFloat, width: CGFloat) {
    let cellWidth = rowWidth / 7
    let startKey = cal.startOfDay(for: slice.interval.start)
    // 종료일은 interval.end 가 다음날 00:00 일 수도 있으니 -1초 또는 -1일/00:00 처리
    let endKey   = cal.startOfDay(for: cal.date(byAdding: .second, value: -1, to: slice.interval.end) ?? slice.interval.end)
    let startCol = cal.dateComponents([.day], from: weekStart, to: startKey).day ?? 0
    let dayCount = (cal.dateComponents([.day], from: startKey, to: endKey).day ?? 0) + 1
    return (x: CGFloat(startCol) * cellWidth,
            width: CGFloat(dayCount) * cellWidth)
}
```

## 구현 가이드

**1) `WeekRowView` 내부에서 토막 계산**

`weekMultidays` 를 그대로 `ForEach` 돌리는 대신, 각각을 `(event, interval)` 슬라이스로 매핑한 다음 그린다.

```swift
private func slices(for events: [Event], in week: DateInterval) -> [(event: Event, interval: DateInterval)] {
    events.compactMap { e in
        let raw = DateInterval(start: e.startDate, end: e.endDate)
        guard let inter = raw.intersection(with: week) else { return nil }
        return (e, inter)
    }
}
```

> `compactMap` — nil 을 거르고 unwrap 까지 한 번에. JS `flatMap` / Java `Stream.flatMap(Optional::stream)` 결.

**2) ForEach 가 받는 데이터 형태**

지금 `ForEach(weekMultidays)` 는 `Event` 의 `Identifiable` (PersistentModel) 을 활용. 슬라이스로 바꾸면 ID 가 필요:

```swift
ForEach(slices, id: \.event.id) { slice in
    let f = barFrame(for: slice, weekStart: weekStart, rowWidth: rowWidth)
    // 본문: 04~06 단계의 바 (Image+Text+background)
}
```

- `id: \.event.id` 로 ID 만 지정.
- 같은 주 안에 같은 이벤트는 한 번만 나오니 id 충돌 없음 (다른 주에는 같은 이벤트가 또 나오지만 각자 다른 `WeekRowView` 인스턴스).

**3) `DateInterval.end` 가 자정 처리**

`cal.dateInterval(of: .weekOfYear, for:)` 의 결과는 보통 **다음 주의 시작 시각**이 `end` 다. 즉 일~토 한 주라면 `end` 는 다음 일요일 00:00. 그래서 `intersection` 결과의 `end` 도 다음 날 00:00 형태일 수 있어, `startOfDay(end)` 를 그대로 쓰면 한 칸 더 길어진다.

→ `cal.date(byAdding: .second, value: -1, to: interval.end)` 로 살짝 앞당겨 본 다음 `startOfDay` 를 통과시키면 그 직전 날의 0시가 나옴. (위 `barFrame` 의 `endKey` 산식.)

## 직접 구현하기
- [ ] `slices(for:in:)` 함수 추가
- [ ] `ForEach(weekMultidays)` → `ForEach(slices(for: weekMultidays, in: weekInterval), id: \.event.id)` 로 교체 (함수 호출 결과 배열을 넘김)
- [ ] `barFrame(...)` 이 슬라이스 interval 의 start/end 로 위치 계산하도록 갱신
- [ ] 시작 주 → 시작일~토요일까지, 중간 주 → 일~토 통째로, 끝 주 → 일~종료일 으로 잘림 확인
- [ ] 7일짜리, 10일짜리, 14일짜리 멀티데이 직접 만들어 보고 각 주 행에서 자기 부분만 보이는지
