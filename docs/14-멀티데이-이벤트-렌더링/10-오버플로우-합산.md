# 단계 10: `+N` 오버플로우 합산

> 새 개념 없음. 셀의 "표시 가능 갯수" 안에서 **멀티데이 lane 우선** + **단일 일** + **남는 건 `+N`** 로 셈을 다시.

## 작업 목표
한 셀이 표시할 수 있는 이벤트 행 수에 한도가 있다 (11번 단계 05 의 `maxVisible = 3`). 멀티데이 lane 이 추가되면서:
- lane 이 capacity 의 일부를 차지
- 남는 자리에 단일 일 이벤트
- 표시되지 않는 단일 일 + (선택) 표시되지 않는 멀티데이 lane 갯수 = `+N`

## 사전 산출물
- `DayCellView` 의 `maxVisible = 3` (조정 가능)
- 09 단계의 `multidayLaneCount` 가 prop 으로 들어옴
- 셀이 받는 `events` 는 그 날의 **단일 일 이벤트만** (05 단계 이후)

## 작업 가이드

**1) capacity 계산**

```swift
private let maxVisible = 3                  // 셀 한 줄당 최대 표시 행 수 (기존)
private var singleDayBudget: Int {
    max(0, maxVisible - multidayLaneCount)  // 멀티데이 lane 이 차지한 나머지
}
```

- 멀티데이 lane 갯수가 maxVisible 을 넘으면 단일 일은 한 개도 못 보임 → `max(0, ...)`.

**2) 표시할 단일 일 갯수와 hidden 갯수**

```swift
private var visibleSingleDays: [Event] {
    Array(events.prefix(singleDayBudget))
}
private var hiddenSingleDayCount: Int {
    max(0, events.count - singleDayBudget)
}
```

**3) `+N` 표시 조건**

기존:

```swift
if events.count > maxVisible {
    HStack { Text("+"); Text("\(events.count - maxVisible)") }
}
```

새:

```swift
if hiddenSingleDayCount > 0 {
    HStack(spacing: 1) {
        Text("+")
        Text("\(hiddenSingleDayCount)")
    }
    .foregroundStyle(.secondary)
    .font(.system(size: 10, weight: .semibold))
    .padding(.leading, 11)
}
```

> 멀티데이 lane 이 잘려서 안 보이는 케이스는? — 위 단순화 안에선 lane 갯수가 무한정 늘어나도 다 그리고, 단일 일만 잘림. lane 상한을 두려면 08 단계의 "조금 더" 처럼 별도 정책.

**4) ForEach 가 `visibleSingleDays` 를 받게**

```swift
ForEach(visibleSingleDays) { e in
    // 기존 단일 일 렌더링
}
```

## 직접 구현하기
- [ ] `singleDayBudget`, `visibleSingleDays`, `hiddenSingleDayCount` 계산 프로퍼티 추가
- [ ] `ForEach(events.prefix(maxVisible))` → `ForEach(visibleSingleDays)` 로 교체
- [ ] `+N` 표시 조건/문구를 hidden 단일 일 갯수 기준으로 변경
- [ ] 케이스별 확인:
  - 멀티데이 0, 단일 일 5 → "+2"
  - 멀티데이 1, 단일 일 5 → 단일 일 2개 표시, "+3"
  - 멀티데이 3, 단일 일 3 → 단일 일 0개 표시, "+3"
  - 멀티데이 5, 단일 일 0 → `+N` 안 보임 (단일 일 hidden 0)

## 자가 점검
- 빌드 통과?
- `+N` 이 멀티데이를 차지한 영역 *아래* 에 자연스럽게 나오는지 (09 의 reserved space 와 함께 봤을 때)
- 셀 capacity 가 5 같이 크게 바뀌어도 식이 그대로 동작하는지 (의존성: `maxVisible` 한 상수)
- 퀴즈: 만약 멀티데이 lane 도 일부 잘라야 한다면 (예: lane 상한 2), `+N` 의 N 은 어떻게 정의하는 게 자연스러운가? (멀티데이 hidden + 단일 hidden 합)

## Claude 리뷰 체크리스트
- [ ] capacity 산식이 `max(0, ...)` 로 안전
- [ ] `+N` 조건이 `> 0` 으로 깔끔
- [ ] `maxVisible` 한 상수에 의존 — 외부 정책 변경에 강함
- [ ] 멀티데이 lane 이 0 일 때 회귀 없음 (11번 단계와 동일 동작)
