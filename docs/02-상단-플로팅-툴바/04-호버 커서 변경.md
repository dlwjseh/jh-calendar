# 단계 4: 버튼 호버 시 손모양 커서

## 학습 목표
- macOS 15 부터 SwiftUI 표준 modifier 인 `.pointerStyle(_:)` 로 마우스 커서를 직접 바꿀 수 있다는 것을 익힌다.
- `PointerStyle` enum 의 옵션들을 둘러보고, 의미에 맞는 커서를 고르는 감을 잡는다.
- "어디에 적용할지" — 각 Button 에 따로 vs HStack 통째로 — 의 트레이드오프를 이해한다.

## 사전 지식
- 단계 1~3 완료: floating 카드(Material 배경) 안에 사이드바 / `+` 두 Button 이 있는 상태.
- 프로젝트 deployment target 이 **macOS 15+** 라는 사실 (`CLAUDE.md` 의 "기술 스택" 참조). 이 단계에서 쓸 modifier 가 macOS 15 부터 등장했기 때문.

## Swift / SwiftUI 개념

### 1) `.pointerStyle(_:)` — macOS 15 의 SwiftUI 표준 cursor modifier

웹에서 `cursor: pointer`, Vue 에서 `style="cursor: pointer"` 한 줄이면 끝나는 그것 — SwiftUI 도 macOS 15 부터는 한 줄이다.

```swift
SomeView()
    .pointerStyle(.link)
```

> 참고: macOS 14 까지는 SwiftUI 표준에 cursor modifier 가 없어서 AppKit 의 `NSCursor` 를 끌어다 써야 했다. iOS 와 공유 layer 인 SwiftUI 에 macOS 전용 기능(커서) 이 늦게 들어온 것. 우리는 deployment target 을 15 로 잡고 있으니 그 우회는 필요 없다. (호기심이 생기면 "조금 더" 항목 참고.)

### 2) `PointerStyle` 의 옵션들

`.link` 외에도 의미별로 여러 가지가 있다. 자주 쓸 만한 것:

| 옵션 | 모양 | 언제 |
|---|---|---|
| `.link` | 손모양 (pointing hand) | 클릭 가능한 버튼/링크 |
| `.default` | 기본 화살표 | 보통의 영역 |
| `.text` | I-beam | 텍스트 입력/선택 영역 |
| `.frameResize(...)` | 양쪽/상하 화살표 | 패널 경계 드래그로 크기 조절 |
| `.columnResize` | 컬럼 폭 조절 | 테이블 컬럼 경계 |
| `.rowResize` | 행 높이 조절 | 테이블 행 경계 |
| `.grabIdle` / `.grabActive` | 손바닥 / 쥔 손 | 드래그로 이동 가능한 콘텐츠 |

> 의미 있는 커서를 의도적으로 골라쓰면 macOS 네이티브 앱 다운 디테일이 살아난다. CSS 의 `cursor: pointer` 만 알던 감각보다 한 칸 더 세밀.

### 3) 어디에 적용할까

- **각 Button 에 따로** — 버튼 hit area 안에서만 손모양. 가장 정확.
- **두 버튼을 감싸는 HStack 에 한 번** — 코드는 짧아지지만 버튼 사이 spacing / 카드 패딩 위에서도 손모양이 됨. 보통 카드 패딩 위에까지 손모양이 오는 건 어색하다.

이번엔 (a) "각 Button 에 따로" 권장. SwiftUI 의 modifier 는 자식 view 의 hit area 까지 정확하게 인식하므로, button label 영역 위에서만 커서가 바뀐다.

## 조금 더 (선택)
- **macOS 14 까지의 우회 방식**: `.onHover { hovering in ... }` 로 hover 진입/이탈을 감지하고, AppKit 의 `NSCursor.pointingHand.push()` / `NSCursor.pop()` (또는 `.set()`) 으로 커서를 바꿨다. 이 패턴을 `extension View { func pointerCursor() -> some View }` 로 묶어 재사용. SwiftUI 가 못 가리는 OS API 를 AppKit 으로 끼워넣는 패턴 — 다른 곳(예: 윈도우 직접 제어, NSPasteboard 같은 시스템 서비스)에서 또 만나니 한 번쯤 직접 짜보면 감이 잡힌다.
- **다른 PointerStyle 실험**: `.text`, `.frameResize`, `.grabIdle` 등을 임시로 적용해보고 모양 차이를 눈으로 확인. macOS 의 시각 언어를 익히는 데 도움.
- **`.help("새 일정 추가")`** 한 줄을 같이 붙이면 hover 시 시스템 tooltip 이 같이 뜬다 — 손모양 + tooltip 조합이 macOS 표준 UX.
- **다음 단계 예고 (05)**: hover 시 배경 색까지 살짝 어두워지게 만들면서, 두 Button 의 중복을 `IconButton` 이라는 작은 뷰로 분리할 예정. 거기에서 `@State` 와 작은 컴포넌트화 패턴을 배운다.
