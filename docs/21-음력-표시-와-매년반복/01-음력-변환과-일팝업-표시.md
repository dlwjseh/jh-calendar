# 단계 1: 음력 변환 유틸 + 일 팝업 음력 표시

## 학습 목표
- `Calendar(identifier: .chinese)` 로 양력 `Date` 를 **음력 월/일**로 변환할 수 있다.
- 일 팝업 헤더에 `(음) 4.13` 형태를 작게 곁들여 표시한다.
- 다음 단계(반복)에서 재사용할 **음력 변환 헬퍼**를 하나 만든다.

## 사전 산출물
- `DayPopupDialog.swift` (12단계) — 헤더에 `Text(dayString)` 가 있는 상태.
- `dayString` 처럼 `DateFormatter` 로 날짜를 문자열로 만드는 패턴은 이미 익숙.

## Swift / SwiftUI 개념

### `Date` 는 "절대 시점", 캘린더는 "해석 렌즈"
`Date` 자체엔 "몇 월 며칠" 이 없다 — 1970 기준 **흐른 시간(절대 시점)** 일 뿐이다. (Java `Instant` 와 같다.) "몇 월 며칠" 은 `Calendar` 라는 렌즈를 통과시켜야 나온다.

→ 그래서 **같은 `Date` 를 다른 캘린더로 해석**하면 다른 월/일이 나온다. 양력 렌즈로 보면 5월 29일, 음력 렌즈로 보면 4월 13일. **데이터(Date)는 그대로, 렌즈만 교체.**

```swift
let date = Date()                                  // 절대 시점 1개
Calendar(identifier: .gregorian).component(.month, from: date)  // 5  (양력)
Calendar(identifier: .chinese).component(.month, from: date)    // 4  (음력)
```

> Java 비교: `Instant` 는 그대로 두고 `Chronology`(역법) 만 바꾸는 것과 같다. 다만 Java 표준엔 음력(Chinese) 크로놀로지가 **없고**, Foundation 은 `.chinese` 를 기본 제공한다. 한국 음력 = 이 `.chinese` 캘린더로 사실상 동일하게 나온다.

### 윤달(`isLeapMonth`)
음력은 양력과 길이를 맞추려고 몇 년에 한 번 **같은 달을 두 번**(윤달) 넣는다. 그래서 음력엔 "윤4월" 같은 게 있다. `dateComponents` 로 이 플래그를 함께 꺼낼 수 있다.

```swift
let lunar = Calendar(identifier: .chinese)
let c = lunar.dateComponents([.month, .day, .isLeapMonth], from: date)
c.month        // 음력 월 (1...12)
c.day          // 음력 일 (1...30)
c.isLeapMonth  // 윤달이면 true (Optional<Bool>)
```

이번 표시 단계에선 윤달이어도 그냥 `(음) 4.13` 으로 둬도 된다(윤달 표식은 선택). 다만 **헬퍼는 윤달 정보까지 꺼내 두면** 다음 단계에서 다시 안 만져도 된다.

### 2) 일 팝업 헤더에 표시
`DayPopupDialog.swift` 의 `dayString` 옆에 음력을 곁들인다. 현재 헤더:

```swift
HStack {
    Text(dayString)
        .font(.system(size: 17, weight: .bold))
        // ... .frame(maxWidth: .infinity, alignment: .leading)
    Button { onAddEvent(date) } label: { ... }  // + 버튼
}
```

바꿀 방향:
- `dayString` 처럼 `lunarString` computed property 를 하나 더 만들거나, `LunarDate.shortLabel(from: date)` 를 바로 쓴다.
- 날짜 텍스트와 음력 텍스트를 **한 덩어리**로 묶어 그 덩어리에 `maxWidth: .infinity, alignment: .leading` 을 준다(그래야 + 버튼이 오른쪽 끝에 그대로 남는다). 작은 `HStack(alignment: .firstTextBaseline)` 으로 감싸는 걸 추천.
- 음력 텍스트는 더 작고 흐리게: `.font(.system(size: 12))`, `.foregroundStyle(.white.opacity(0.8))` 정도.

```swift
HStack(alignment: .firstTextBaseline, spacing: 6) {
    Text(dayString) ...
    Text(LunarDate.shortLabel(from: date))   // (음) 4.13
        // TODO: 작게/흐리게 스타일
}
.frame(maxWidth: .infinity, alignment: .leading)
```

> baseline 정렬을 쓰는 이유: 폰트 크기가 다른 두 텍스트의 **글자 밑선**을 맞춰야 나란히 자연스럽다. (위/아래로 둥둥 뜨는 걸 방지.)

## 조금 더 (선택)
- `DateFormatter` 에 `.calendar` 와 `.locale` 을 음력으로 지정해도 변환된다(`f.calendar = Calendar(identifier: .chinese)`). 다만 연/간지까지 끼어들 수 있어, 월·일만 깔끔히 쓰려면 컴포넌트 직접 추출이 더 다루기 쉽다.
- 한국천문연구원 음력과 `.chinese` 캘린더는 현대 구간에서 거의 일치하지만, 신월 계산 시각(시간대) 차이로 **드물게 하루 어긋나는** 해가 있다. 학습/일상용으론 무시 가능. 완전 정합이 필요하면 별도 음력 테이블이 필요하다.
