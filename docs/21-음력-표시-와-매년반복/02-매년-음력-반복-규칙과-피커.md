# 단계 2: `매년 음력` 반복 규칙(enum) + 피커 라벨

> 이번 단계는 **거의 새 개념이 없다.** 19단계에서 만든 enum + 피커 패턴에 케이스 하나를 더 얹는 "적용" 단계다.

## 작업 목표
- `RecurrenceRule` 에 `yearlyLunar` 케이스를 추가한다.
- 반복 피커에 **`매년 음력 N월 N일`** 항목이 자동으로 뜨고, 선택·저장된다.
- (펼치기/실제 표시는 **다음 단계 03**. 여기까진 피커에 보이고 저장만 되면 OK.)

## 사전 산출물
- `EventModels.swift` — `enum RecurrenceRule: String, Codable, CaseIterable { case none, daily, weekly, monthly, yearly }`
- `AddEventDialog.swift` — `label(for:)` 가 규칙별 한글 라벨을 만들고, `Menu` 가 `RecurrenceRule.allCases` 를 순회해 버튼을 만든다.
- `LunarDate` 헬퍼 (01단계).

## 왜 케이스만 추가하면 피커에 자동으로 뜨나
피커는 `ForEach(RecurrenceRule.allCases, ...)` 로 돈다. `CaseIterable` 의 `allCases` 는 **선언 순서대로** 모든 케이스를 담은 배열이라, enum 에 케이스를 추가하면 메뉴 항목도 **자동으로 하나 늘어난다.** (19단계에서 이미 본 성질 → [19-03](../19-이벤트-반복/03-반복-피커-저장연결.md).)

저장 측도 안전하다: `RecurrenceRule` 은 `String` rawValue 로 SwiftData 에 들어간다(`yearlyLunar` 라는 문자열로 저장). **기존에 저장된 이벤트**들은 자기 rawValue 그대로라 영향이 없다 — 케이스 추가는 하위호환.

## 구현 가이드

### 1) enum 케이스 추가
`EventModels.swift`:

```swift
enum RecurrenceRule: String, Codable, CaseIterable {
    case none, daily, weekly, monthly, yearly, yearlyLunar
    //                                          ^ 추가
}
```
- `yearly` **뒤**에 두면 메뉴에서도 `매년 …` 바로 아래에 자연스럽게 붙는다.

### 2) 라벨 추가
`AddEventDialog.swift` 의 `label(for:)` 에 케이스 추가. 양력 `yearly` 가 `startDate` 의 월/일을 쓰듯, `yearlyLunar` 는 **음력 월/일**(01단계 헬퍼)을 쓴다.

```swift
private func label(for rule: RecurrenceRule) -> String {
    let cal = Calendar.current
    switch rule {
    case .none:    return "반복 안 함"
    // ... daily / weekly / monthly / yearly 그대로 ...
    case .yearlyLunar:
        let l = LunarDate.components(from: startDate)
        return "매년 음력 \(l.month)월 \(l.day)일"   // 윤달이면 "윤\(l.month)월" 로 해도 됨(선택)
    }
}
```

힌트:
- `switch` 가 모든 케이스를 다뤄야 하므로, 케이스를 추가하면 컴파일러가 `label(for:)` 에서 **"빠진 케이스 있다"** 고 에러를 낸다. 이게 enum 의 장점 — 새 케이스 처리 누락을 컴파일 타임에 잡아준다. (Java `switch` 에 `default` 로 뭉개는 것과 대조: Swift 는 exhaustive 를 강제.)
- 라벨 외에 다른 곳(피커 `Menu`, `label(for: recurrence)`)은 **건드릴 필요 없다** — 이미 `allCases` / 같은 함수를 쓰므로.

## 자가 점검
- 빌드 통과?
- 이벤트 다이얼로그에서 반복 메뉴를 열면 **`매년 음력 N월 N일`** 이 보이나? (N 이 시작일의 음력 월/일과 맞나?)
- 그걸 선택하고 저장 → 다시 수정 다이얼로그를 열면 그 값이 유지되나? (`.edit` 진입 시 `recurrence` 복원)
- 아직 달력엔 **원래 날짜에만** 표시될 것이다(펼치기 미구현). 정상 — 03단계에서 채운다.
