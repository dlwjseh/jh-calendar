# 음력 표시 + 매년 음력 반복

## 목표
- 일 팝업 다이얼로그 상단의 날짜 옆에 **음력**을 작게 표시한다 (예: `5월 29일 (금)  (음) 4.13`).
- 반복 규칙에 **`매년 음력 N월 N일`** 을 추가해, 양력으론 매년 날짜가 바뀌는 음력 기념일(생일·제사 등)을 반복 표시한다.

## 의존 관계
- 사전 필요:
  - `12-일-팝업` — `DayPopupDialog` 헤더(날짜 텍스트)를 손본다.
  - `19-이벤트-반복` — `RecurrenceRule` enum / `AddEventDialog` 피커 / `RecurrenceExpander` 펼치기 엔진. **이 위에 케이스 하나를 더 얹는다.**
- 이후 영향:
  - "음력 생일 알림", "양/음력 토글 보기" 같은 기능을 이 위에 올릴 수 있음.

## 이 기능에서 학습할 Swift / SwiftUI 개념

**새로 등장**:
- **`Calendar(identifier: .chinese)`** — 그레고리력이 아닌 다른 역법(음력) 캘린더. `Date`(절대 시점)는 그대로 두고 **해석 렌즈만 바꾼다**.
- **윤달(`isLeapMonth`)** — 음력에만 있는 개념. `dateComponents` 로 꺼내기.
- **다른 캘린더로 `enumerateDates`** — 매칭 컴포넌트(월/일)를 **음력 기준으로** 해석시켜, 매년의 양력 날짜를 찾아내기.

**다시 쓰는 개념** (링크):
- `enum: String, Codable, CaseIterable` + 피커 자동 노출 → [19-02 반복 규칙 데이터 모델](../19-이벤트-반복/02-반복-규칙-데이터-모델.md) / [19-03 반복 피커](../19-이벤트-반복/03-반복-피커-저장연결.md)

## 범위 / 비범위
- **음력 → 양력 변환은 `.chinese` 캘린더에 맡긴다.** 직접 음력 알고리즘을 짜지 않는다.
- 표시는 **`(음) 월.일`** 한 가지 포맷. 윤달이면 표식 하나만 덧붙이는 선까지(03 참고).
- 반복은 **`매년 음력`** 하나만 추가. `매월 음력` 등은 범위 밖.
- 음력 날짜가 그 해에 없을 때(음력 30일이 없는 달 등)는 그 해 **skip** (양력 `2/29` 처리와 동일 사상).
