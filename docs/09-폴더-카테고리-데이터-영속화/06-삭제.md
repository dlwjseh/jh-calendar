# 단계 6: 삭제 (폴더 / 카테고리)

## 작업 목표
사이드바 행을 마우스 우클릭(또는 길게 누르면) 뜨는 **context menu** 로 폴더/카테고리를 삭제한다. 폴더 삭제 시 안의 카테고리가 cascade 로 함께 제거되는지 검증.

> 새 Swift 개념: SwiftUI 의 `.contextMenu { }` modifier + `modelContext.delete(_:)`. 그 외엔 4~5단계 패턴의 거울상.

## 사전 지식
- `@Environment(\.modelContext)`, `modelContext.insert` → [04-폴더 추가 저장 + 첫 실행 시드.md](./04-폴더%20추가%20저장%20%2B%20첫%20실행%20시드.md) 참고
- `@Relationship(deleteRule: .cascade, ...)` 설정 → [02-Category @Model + Relationship.md](./02-Category%20@Model%20%2B%20Relationship.md) 참고

## Swift / SwiftUI 개념 (작게)

### `.contextMenu { ... }` modifier
어떤 뷰에 붙이면 우클릭 시 그 안의 Button 들이 메뉴로 뜬다. macOS 의 표준 UX.

```swift
Text(folder.name)
    .contextMenu {
        Button("이름 변경") { /* 7단계에서 */ }
        Button("삭제", role: .destructive) {
            modelContext.delete(folder)
        }
    }
```

`role: .destructive` 는 텍스트를 빨갛게 칠해주고 키보드 내비게이션에서도 위험 액션으로 인지된다.

### `modelContext.delete(_:)`
JPA 의 `entityManager.remove(e)` 와 같다. 관계의 `deleteRule` 에 따라 자식까지 따라간다 — 폴더에 `.cascade` 를 걸어둔 덕에 폴더만 지우면 카테고리도 한 번에 사라진다.

> 명시적 `save()` 불필요. 자동 저장에 맡긴다.

## 작업 가이드

### 파일 변경 계획
- `Sidebar.swift` 또는 폴더 헤더 영역 — `Text(folder.name)` 에 `.contextMenu { ... 삭제 버튼 }` 부착
- `CategoryRow.swift` — 행 전체에 `.contextMenu` 부착, 삭제 버튼에서 `modelContext.delete(category)`
- 두 곳 모두 `@Environment(\.modelContext)` 를 추가로 받아야 함

### 확인 사항
- 폴더 삭제 후 그 안에 있던 카테고리들이 모두 사라졌는지 (`@Query` 의 `Category` 전체 목록을 잠시 print 해보거나, 다른 폴더 안에 잘못 옮겨 가진 않았는지)
- 마지막 폴더를 삭제한 뒤 다이얼로그를 다시 띄워도 빈 상태가 정상으로 보이는지
- 시드 정책과의 상호작용 — `folders.isEmpty` 만으로 시드를 다시 넣으면, 사용자가 "전부 지운 상태" 가 보존되지 않는다. 4단계에서 어떤 정책을 골랐는지 다시 점검.

### 막힐 만한 지점 — 힌트

- **확인 다이얼로그 (alert) 까지 띄울지** — 캘린더 데이터가 적은 지금은 굳이 alert 없이 즉시 삭제도 충분. 나중에 일정이 붙으면 confirmation dialog 를 추가하자.
- **context menu 가 너무 좁은 영역에서만 뜬다** — 폴더 헤더의 `Text` 만이 아니라 그 행의 컨테이너 `HStack`/`VStack` 에 붙이면 더 넓은 영역에서 우클릭이 먹는다.
- **삭제 후 UI 가 1초 정도 그대로** — 시뮬레이션 환경에서 `@Query` 가 인식하는 데 약간 지연되는 경우가 있음. 보통은 즉시 사라진다. 안 사라지면 컨텍스트가 다른 인스턴스를 가리키고 있을 가능성 (delete 한 객체가 우리가 잡고 있는 그 객체가 맞는지 점검).
- **`role: .destructive` 가 텍스트 색을 안 바꾼다** — macOS 14~15 에서 일부 버전 이슈가 있을 수 있음. 색을 강제하고 싶다면 Label/Text 에 직접 `.foregroundStyle(.red)`.

## 자가 점검
- 폴더 우클릭 → 삭제 → 사이드바에서 폴더 + 카테고리 모두 사라지는가?
- 카테고리 단독 삭제 시 폴더는 그대로 남는가?
- 마지막 폴더 삭제 후 재시작 시 시드가 다시 들어오는가, 아니면 사용자의 "비움" 상태가 보존되는가? — 어느 쪽이 본인 의도와 맞는지 확인.
- 이해도 퀴즈
  1. 만약 `.cascade` 대신 `.nullify` 였다면 폴더 삭제 후 카테고리들은 어떻게 됐을까?
  2. context menu 에 적어둔 액션은 본문에서 컴파일 시점에 결정되는가, 런타임 시점에 결정되는가?
