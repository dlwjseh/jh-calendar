# 단계 5: 카테고리 추가 저장

## 작업 목표
`AddCategoryDialog` 가 선택된 폴더에 실제 `Category` 를 추가하고, 색상까지 영속화되게 만든다. 사이드바가 즉시 갱신되는 것까지 확인.

> 이 단계는 4단계 (폴더 추가 저장) 의 패턴 반복 + 관계 연결이 추가될 뿐. 새 Swift 개념은 거의 없다.

## 사전 지식
- 4단계 산출물 — `modelContext.insert(...)` 패턴이 익숙해진 상태
- `@Environment(\.modelContext)` → [04-폴더 추가 저장 + 첫 실행 시드.md](./04-폴더%20추가%20저장%20%2B%20첫%20실행%20시드.md) 참고
- `@Relationship` 양방향 관계 → [02-Category @Model + Relationship.md](./02-Category%20@Model%20%2B%20Relationship.md) 참고

## 작업 가이드

### 두 가지 등록 방식 — 어느 쪽을 골라도 결과는 같다

**A. 폴더의 컬렉션에 직접 추가 (권장)**
```swift
let category = Category(name: trimmed, color: selectedColor, isChecked: true)
selectedFolder.categories.append(category)
// SwiftData 는 관계로 연결된 새 인스턴스도 자동 인식 → 별도 insert 불필요
```

**B. 명시적 insert + folder 세팅**
```swift
let category = Category(name: trimmed, color: selectedColor, isChecked: true)
category.folder = selectedFolder
modelContext.insert(category)
```

> Spring JPA 의 "양방향 관계는 양쪽 다 세팅" 권장과 같은 결. A 가 더 SwiftUI 스럽지만, B 가 더 명시적. 한쪽으로 일관되게 가자.

### 파일 변경 계획
- `AddCategoryDialog.swift`
  - `@Environment(\.modelContext) private var modelContext` 추가
  - 저장 버튼의 `print(...)` 를 실제 등록 로직으로 교체
  - `selectedFolderID` 로 폴더를 찾아 그 폴더에 카테고리 append
- (선택) `ContentView` 의 시드에 카테고리도 함께 — 첫 실행 때 iCloud/기타 폴더 안에 기본 카테고리 몇 개를 넣어주면 사용감이 자연스럽다. 시드 정책은 4단계와 일관되게.

### 핵심 골격

```swift
struct AddCategoryDialog: View {
    @Binding var isPresented: Bool
    @Environment(\.modelContext) private var modelContext
    let folders: [Folder]
    @State private var selectedFolderID: UUID? = nil   // ← 주의: 아래 힌트 참조
    ...

    private func save() {
        guard
            let folder = folders.first(where: { ??? }),
            !name.trimmingCharacters(in: .whitespaces).isEmpty
        else { return }
        let category = Category(name: trimmedName,
                                color: selectedColor,
                                isChecked: true)
        folder.categories.append(category)
    }
}
```

### 막힐 만한 지점 — 힌트

- **`Folder` 의 `id` 가 `UUID` 가 아닐 수 있다** — `@Model` 매크로가 자동 부여하는 `PersistentIdentifier` 는 `UUID` 가 아니다. 다이얼로그에서 폴더를 식별할 때는 두 가지 선택:
  1. `Folder` 인스턴스(참조) 자체를 들고 다니기 — class 라서 `==` 비교나 `===` 가능. `@State private var selectedFolder: Folder? = nil` 로 가는 게 가장 깔끔.
  2. 정말 `UUID` 키가 필요하면 `Folder` 에 `var id: UUID = UUID()` 저장 프로퍼티를 따로 두기 (가능하지만 보통은 불필요).
- **`Menu { Button(folder.name) { ... } }` 안에서 폴더 선택** — Button 액션에서 `selectedFolder = folder` 로 인스턴스를 직접 잡으면 된다.
- **카테고리가 추가됐는데 사이드바 색깔이 회색/검정** — Color → hex 변환에서 sRGB 변환을 빼먹었을 가능성. [03-Color 영속화.md](./03-Color%20영속화.md) 의 sRGB 변환 부분 재점검.
- **선택 폴더가 nil 인데 저장 버튼이 활성화** — `isSaveEnabled` 가드를 `selectedFolder != nil` 로 갱신.
