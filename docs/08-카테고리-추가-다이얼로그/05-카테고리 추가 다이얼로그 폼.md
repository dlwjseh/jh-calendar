- 저장 시 `print` 후 닫힘. (실제 추가는 다음 기능.)

## Swift / SwiftUI 개념

### 1. `Menu` — macOS 시스템 드롭다운

```swift
@State private var selectedFolderID: UUID? = nil

Menu {
    ForEach(folders) { folder in
        Button(folder.name) { selectedFolderID = folder.id }
    }
} label: {
    HStack {
        Text(selectedFolder?.name ?? "폴더 선택")
            .foregroundStyle(selectedFolder == nil ? .secondary : .primary)
        Spacer()
        Image(systemName: "chevron.down")
            .font(.caption)
    }
}
.menuStyle(.borderlessButton)
```

- `Menu { 항목들 } label: { 트리거 view }` — `label` 클릭 시 항목 목록이 뜨고, 항목 클릭 시 자동으로 닫힘.
- macOS 의 표준 dropdown — Vue/HTML 의 `<select>` 와 의미는 같지만, **trigger view 를 자유롭게 디자인** 할 수 있다는 게 큰 차이.

> SwiftUI `Picker(selection:, label:)` 도 비슷한 역할. `Menu` 가 더 자유롭다. 학습적으로는 `Picker` 부터 시작해도 OK.

`selectedFolder` 계산:
```swift
private var selectedFolder: Folder? {
    folders.first(where: { $0.id == selectedFolderID })
}
```

> ID 만 들고 `first(where:)` 로 찾는 패턴 — 모델 객체를 직접 `@State` 로 들면 update 가 까다로워서 ID 만 들고 보는 게 흔한 관용. Spring/JPA 에서 엔티티 전체 대신 ID 만 들고 다니는 것과 같은 결.

### 2. `LazyVGrid` + `GridItem` — 격자 레이아웃

> CSS Grid 비유: `grid-template-columns: repeat(4, 1fr)` 와 가장 비슷한 발상.

```swift
let columns: [GridItem] = Array(repeating: GridItem(.flexible(), spacing: 12), count: 4)

LazyVGrid(columns: columns, spacing: 12) {
    ForEach(palette, id: \.self) { color in
        // 색 셀
    }
}
```

- `GridItem(.flexible())` — 각 열이 가용 너비를 균등 분할. (다른 옵션: `.fixed(40)`, `.adaptive(minimum: 40)`)
- `spacing: 12` — 같은 행 안 셀들 사이 간격 + 행 사이 간격.
- `LazyVGrid` 의 "Lazy" — 화면에 보이는 것만 그린다. 12 개짜리 그리드엔 큰 의미 없지만, 수백 개 셀이면 차이가 큼.

### 3. 임의 색상 정의 — `Color(red:green:blue:)` / hex

SwiftUI `Color` 는 `.red`, `.blue` 같은 시스템 컬러 외에 직접 RGB 로도 만들 수 있다.

```swift
Color(red: 1.0, green: 0.55, blue: 0.36)   // 0~1 정규화 값
```

또는 hex extension — 시스템엔 없어서 자주 직접 만든다:

```swift
extension Color {
    init(hex: UInt32) {
        let r = Double((hex >> 16) & 0xFF) / 255
        let g = Double((hex >>  8) & 0xFF) / 255
        let b = Double( hex        & 0xFF) / 255
        self.init(red: r, green: g, blue: b)
    }
}

Color(hex: 0xFFB562)
```

> Java 비유: `extension` 은 Kotlin 의 extension function 과 동일한 개념. **기존 타입에 새 메서드/이니셜라이저를 비-침습적으로 추가**. Java 의 utility class — `Colors.fromHex(0xFFB562)` — 가 호출자 입장에서 `Color(hex: 0xFFB562)` 처럼 자연스러워지는 그림.

### 4. 선택 상태 시각화 — `Color: Equatable`

`Color` 는 `Equatable` 이라 `==` 비교 가능. 선택된 색을 `@State` 로 들고 비교해서 border 를 그린다.

```swift
@State private var selectedColor: Color = CategoryColorPalette.all.first ?? .blue

ForEach(palette, id: \.self) { color in
    RoundedRectangle(cornerRadius: 6)
        .fill(color)
        .frame(width: 36, height: 36)
        .overlay(
            RoundedRectangle(cornerRadius: 6)
                .stroke(.primary, lineWidth: selectedColor == color ? 2 : 0)
                .padding(-3)                  // 외곽으로 살짝 띄우기
        )
        .onTapGesture { selectedColor = color }
}
```

> 디자인 디테일은 자유. `border` 대신 옅은 그림자 / 체크마크 오버레이도 OK. 핵심은 "선택된 것 vs 아닌 것" 을 시각으로 구분.

`id: \.self` 의 의미: `ForEach` 가 각 element 의 식별자를 element 자체로 사용. `Color` 가 `Hashable` 이라 가능.

## 구현 가이드

### 1. `CategoryColorPalette.swift` 신설

`JHCalendar/Features/Sidebar/CategoryColorPalette.swift`:

```swift
import SwiftUI

enum CategoryColorPalette {
    // 4 x 3 = 12 색. hex 는 대략값 — 눈으로 보고 미세 조정.
    static let all: [Color] = [
        Color(hex: 0xFFC369),   // 행1: peach yellow
        Color(hex: 0xFF8B5C),   //      orange
        Color(hex: 0xFF6B6B),   //      red-orange
        Color(hex: 0xFF5C7C),   //      coral

        Color(hex: 0xFF8AA6),   // 행2: pink
        Color(hex: 0xFF4D8D),   //      hot pink
        Color(hex: 0xFFA5D8),   //      light pink
        Color(hex: 0x8B9EE0),   //      periwinkle

        Color(hex: 0x6FB6E0),   // 행3: light blue
        Color(hex: 0x5DD4D4),   //      teal
        Color(hex: 0x3AB89E),   //      green-teal
        Color(hex: 0xA4D858),   //      lime
    ]
}

extension Color {
    init(hex: UInt32) {
        let r = Double((hex >> 16) & 0xFF) / 255
        let g = Double((hex >>  8) & 0xFF) / 255
        let b = Double( hex        & 0xFF) / 255
        self.init(red: r, green: g, blue: b)
    }
}
```

> hex 값은 추정. macOS 기본 앱 "Digital Color Meter" 로 찍어보고 미세 조정 권장. 학습 자체엔 영향 없음.

### 2. 폴더 목록을 다이얼로그로 전달

> 현재 `folders` 는 `Sidebar` 의 `@State` 안에 있다. 다이얼로그는 `ContentView` 가 그리므로, 다이얼로그가 폴더 목록을 알려면 ContentView 도 알아야 한다.
>
> 이번 단계에선 학습 부담을 줄이기 위해 **`Folder.sample` 을 stub 으로 직접 참조** 한다. 폴더를 추가해도 sample 이 갱신되진 않지만, 어차피 이번 기능은 `print` 만 하므로 OK. **다음 기능** 에서 `CalendarStore` (또는 SidebarStore) 로 `folders` 를 끌어올려 진짜로 연결한다.

선택지 둘 중 하나:

**(A) 가장 단순** — 다이얼로그가 sample 직접 참조:

```swift
struct AddCategoryDialog: View {
    @Binding var isPresented: Bool
    private let folders: [Folder] = Folder.sample   // stub
    // ...
}
```

**(B) 조금 더 깔끔** — ContentView 가 같은 stub 을 들고 `let` 으로 넘김:

```swift
// ContentView
private let folderStubs: [Folder] = Folder.sample
// ...
AddCategoryDialog(
    isPresented: $isAddCategoryPresented,
    folders: folderStubs
)
```

> 다음 기능에서 stub → 실제 store 로 갈아끼울 때 (B) 가 한 군데만 바꾸면 되니 살짝 유리. 어느 쪽이든 학습 목표엔 무관.

### 3. `AddCategoryDialog` 본격 구현

```swift
struct AddCategoryDialog: View {
    @Binding var isPresented: Bool
    let folders: [Folder]                                       // 또는 stub

    @State private var selectedFolderID: UUID?
    @State private var name: String = ""
    @State private var selectedColor: Color = CategoryColorPalette.all.first ?? .blue

    private var selectedFolder: Folder? {
        folders.first(where: { $0.id == selectedFolderID })
    }

    private var isSaveEnabled: Bool {
        selectedFolderID != nil &&
        !name.trimmingCharacters(in: .whitespaces).isEmpty
    }

    private let columns: [GridItem] = Array(repeating: GridItem(.flexible(), spacing: 12), count: 4)

    var body: some View {
        VStack(alignment: .leading, spacing: 20) {
            Text("카테고리 추가").font(.headline)

            // 1. 폴더 선택 — 맨 위
            VStack(alignment: .leading, spacing: 6) {
                Text("폴더").font(.caption).foregroundStyle(.secondary)
                Menu {
                    ForEach(folders) { folder in
                        Button(folder.name) { selectedFolderID = folder.id }
                    }
                } label: {
                    HStack {
                        Text(selectedFolder?.name ?? "폴더 선택")
                            .foregroundStyle(selectedFolder == nil ? .secondary : .primary)
                        Spacer()
                        Image(systemName: "chevron.down").font(.caption)
                    }
                    .padding(.vertical, 6)
                    .padding(.horizontal, 10)
                    .background(.gray.opacity(0.12))
                    .clipShape(.rect(cornerRadius: 6))
                }
                .menuStyle(.borderlessButton)
            }

            // 2. 이름
            VStack(alignment: .leading, spacing: 6) {
                Text("이름").font(.caption).foregroundStyle(.secondary)
                TextField("카테고리 이름", text: $name)
                    .textFieldStyle(.roundedBorder)
            }

            // 3. 색상 팔레트
            VStack(alignment: .leading, spacing: 6) {
                Text("색상").font(.caption).foregroundStyle(.secondary)
                LazyVGrid(columns: columns, spacing: 12) {
                    ForEach(CategoryColorPalette.all, id: \.self) { color in
                        // TODO: 색 셀 + 선택 표시 + 탭 핸들러 (위 "선택 상태 시각화" 참고)
                    }
                }
            }

            // 4. 버튼
            HStack {
                Button("취소") { isPresented = false }
                    .keyboardShortcut(.cancelAction)
                Spacer()
                Button("저장") {
                    print("카테고리 저장: folder=\(selectedFolder?.name ?? "?"), name=\(name), color=\(selectedColor)")
                    isPresented = false
                }
                .keyboardShortcut(.defaultAction)
                .disabled(!isSaveEnabled)

            .padding(.top, 4)

        .clipShape(.rect(cornerRadius: 12))
        .shadow(color: .black.opacity(0.3), radius: 20, y: 8)
    }
}
```

색 셀 부분은 위 "선택 상태 시각화" 코드를 참고해 직접 작성. `ForEach` 안 `TODO` 부분만 채우면 됨.

## 조금 더 (선택)
- `Picker(selection:, label:)` 와 `Menu` 의 차이 — 같은 일을 두 가지 방식으로.
- 색상 팔레트를 `enum CategoryColor: CaseIterable { case peach, orange, ... }` + `var color: Color { ... }` 패턴으로. 저장 시 hex 가 아닌 case 이름으로 직렬화하기 좋음 (영속화 고려 시).
- 색 이름을 같이 보여주기 — 접근성 (색맹 사용자).
- `@FocusState` 로 다이얼로그 뜨자마자 이름 TextField 에 포커스 — 단계 04 참고.
- `Form` / `LabeledContent` — macOS 설정창 스타일 폼.
