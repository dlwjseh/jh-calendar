## Swift / SwiftUI 개념

### 1. `TextField` — Vue 의 `v-model` 과 같은 양방향 바인딩

```swift
@State private var name = ""

TextField("카테고리 이름", text: $name)
    .textFieldStyle(.roundedBorder)
```

- 첫 인자 `"카테고리 이름"` 은 **placeholder** (Vue 의 `:placeholder`).
- `text: $name` — `$` 는 `Binding<String>`. TextField 안에서의 변경이 `name` 으로 흘러나오고, 외부에서 `name` 을 바꾸면 TextField 에도 반영. 정확히 `v-model="name"` 과 같은 발상.
- `.textFieldStyle(.roundedBorder)` — macOS 에서 자연스러운 외곽선. 기본 스타일은 너무 평범하다.

빈 문자열 검사:

```swift
let isNameEmpty = name.trimmingCharacters(in: .whitespaces).isEmpty
```

> 공백만 입력한 경우도 빈 것으로 취급. `String.trimmingCharacters(in:)` 는 Java 의 `String.strip()` 과 동일.

### 2. `LazyVGrid` + `GridItem` — 격자 레이아웃

> CSS Grid 비유: `grid-template-columns: repeat(4, 1fr)` 와 가장 비슷한 발상.

```swift
let columns: [GridItem] = Array(repeating: GridItem(.flexible(), spacing: 12), count: 4)

LazyVGrid(columns: columns, spacing: 12) {
    ForEach(palette, id: \.self) { color in
        // ...
    }
}
```

- `GridItem(.flexible())` — 각 열이 가용 너비를 균등 분할. (다른 옵션: `.fixed(40)`, `.adaptive(minimum: 40)`)
- `spacing: 12` — 같은 행 안 셀들 사이 간격 (`columns` 의 spacing) + 행 사이 간격 (`LazyVGrid` 의 spacing).
- `LazyVGrid` 의 "Lazy" — 화면에 보이는 것만 그린다. 12 개짜리 작은 그리드엔 큰 의미 없지만, 수백 개 셀이면 차이가 큼. (`VGrid` 라는 non-lazy 버전은 SwiftUI 에 없고, 대신 그냥 `VStack { HStack { ... } HStack { ... } ... }` 가 그 역할.)

### 3. 임의 색상 정의 — `Color(red:green:blue:)` / hex

SwiftUI `Color` 는 `.red`, `.blue` 같은 시스템 컬러 외에 직접 RGB 로도 만들 수 있다.

```swift
Color(red: 1.0, green: 0.55, blue: 0.36)   // 0~1 정규화 값 (Float)
```

또는 hex 를 받는 init 을 직접 만들기 — 시스템엔 없어서 extension 으로 자주 만든다:

```swift
extension Color {
    init(hex: UInt32) {
        let r = Double((hex >> 16) & 0xFF) / 255
        let g = Double((hex >>  8) & 0xFF) / 255
        let b = Double( hex        & 0xFF) / 255
        self.init(red: r, green: g, blue: b)
    }
}

// 사용
Color(hex: 0xFFB562)
```

> Java 비유: `extension` 은 Kotlin 의 extension function 과 동일한 개념이지만, 사용자가 Java 만 알면 처음일 것. **기존 타입에 새 메서드/이니셜라이저를 비-침습적으로 추가** 하는 Swift 의 기능. (Java 의 utility class — `Colors.fromHex(0xFFB562)` — 가 호출자 입장에서 자연스럽게 `Color(hex: 0xFFB562)` 가 되는 그림.)

### 4. 선택 상태 시각화 — `Color: Equatable`

`Color` 는 `Equatable` 이라 `==` 비교 가능. 선택된 색을 `@State` 로 들고, 같은지 비교해서 border 를 그린다.

```swift
@State private var selectedColor: Color = palette.first ?? .blue

ForEach(palette, id: \.self) { color in
    RoundedRectangle(cornerRadius: 6)
        .fill(color)
        .frame(width: 36, height: 36)
        .overlay(
            RoundedRectangle(cornerRadius: 6)
                .stroke(.primary, lineWidth: selectedColor == color ? 2 : 0)
                .padding(-3)                  // 외곽으로 살짝 띄우기
        )
        .onTapGesture { selectedColor = color }
}
```

> 디자인 디테일은 자유. `border` 대신 옅은 그림자 / 체크마크 오버레이도 OK. 핵심은 "선택된 것 vs 아닌 것" 을 시각으로 구분.

`id: \.self` 의 의미: `ForEach` 가 각 element 의 식별자를 element 자체로 사용. `Color` 가 `Hashable` 이라 가능.

### 5. `.disabled(...)` — 조건부 버튼 비활성화

```swift
Button("저장") { save() }
    .disabled(name.trimmingCharacters(in: .whitespaces).isEmpty)
```

비활성 상태가 되면 시스템이 알아서 회색으로 칠해주고 클릭도 무시한다. 별도 스타일링 불필요.

### 1. `CategoryColorPalette.swift` 신설

```swift
import SwiftUI

enum CategoryColorPalette {
    // 이미지의 4 x 3 = 12 색. hex 는 대략값 — 눈으로 보고 미세 조정.
    static let all: [Color] = [
        Color(hex: 0xFFC369),   // 행1: peach yellow
        Color(hex: 0xFF8B5C),   //      orange
        Color(hex: 0xFF6B6B),   //      red-orange
        Color(hex: 0xFF5C7C),   //      coral

        Color(hex: 0xFF8AA6),   // 행2: pink
        Color(hex: 0xFF4D8D),   //      hot pink
        Color(hex: 0xFFA5D8),   //      light pink
        Color(hex: 0x8B9EE0),   //      periwinkle

        Color(hex: 0x6FB6E0),   // 행3: light blue
        Color(hex: 0x5DD4D4),   //      teal
        Color(hex: 0x3AB89E),   //      green-teal
        Color(hex: 0xA4D858),   //      lime

}

extension Color {
    init(hex: UInt32) {
        let r = Double((hex >> 16) & 0xFF) / 255
        let g = Double((hex >>  8) & 0xFF) / 255
        let b = Double( hex        & 0xFF) / 255

```

> 위 hex 값은 추정치. 이미지를 디지털 컬러 미터 (macOS 기본 앱) 로 찍어보고 미세 조정 권장. 학습 자체엔 영향 없음.

### 2. `AddCategoryDialog` 본격 구현

struct AddCategoryDialog: View {

            VStack(alignment: .leading, spacing: 6) {
                Text("색상").font(.caption).foregroundStyle(.secondary)
                LazyVGrid(columns: columns, spacing: 12) {
                    ForEach(CategoryColorPalette.all, id: \.self) { color in
                        // TODO: 색 셀 + 선택 표시 + 탭 핸들러
                    }
                }
            }

            // 버튼
            HStack {

## 조금 더 (선택)
- `Form` / `LabeledContent` — macOS 의 설정창 같은 폼 레이아웃. 다이얼로그를 더 시스템스럽게 만들고 싶다면.
- `@FocusState` — 다이얼로그가 뜨자마자 TextField 에 포커스 가게 하기.
- `.onSubmit` — TextField 에서 Enter 키로 저장 트리거.
- 색상 팔레트를 enum case 로 만들기 — `enum CategoryColor: CaseIterable { case peach, orange, ... }` + `var color: Color { ... }` 패턴. 저장될 때 색을 hex 가 아닌 case 이름으로 직렬화하기 좋음 (다음 기능에서 영속화 고려 시).
- Color 와 색 이름을 같이 보여주기 — 색맹 사용자를 위한 접근성.
