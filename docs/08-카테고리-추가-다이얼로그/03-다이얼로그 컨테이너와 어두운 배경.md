# 단계 3: 다이얼로그 컨테이너 + 어두운 배경 + 닫기 3종

## 학습 목표
- 화면 전체를 덮는 어두운 dim 레이어 위에 **중앙 카드** 를 띄우는 모달 패턴을 구현한다.
- **세 가지 닫기 방법** 을 다 붙인다: 취소 버튼 / 배경 클릭 / ESC 키.
- 이벤트 전파 개념을 짚는다 — 카드 안을 클릭했을 땐 닫히지 않아야 한다.
- **두 다이얼로그 placeholder** (폴더 / 카테고리) 를 모두 이 단계에서 띄울 수 있게 한다.

## 사전 지식
- 단계 02 — `isAddFolderPresented` / `isAddCategoryPresented` 이 `ContentView` 에 있고, 팝오버 메뉴 항목이 둘 중 하나를 `true` 로 세팅함.
- `ZStack` / `overlay` → [01-타이틀바-호버표시](../01-타이틀바-호버표시/) 및 `ContentView` 의 traffic light overlay 참고.

## Swift / SwiftUI 개념

### 1. 모달 overlay 패턴 — `.sheet` 가 아닌 직접 ZStack

SwiftUI 기본 제공 `.sheet(isPresented:)` 는 macOS 에서 **타이틀바 아래로 슬라이드 다운하는 시스템 시트** 다. 화면 중앙에 어두운 배경 + 카드를 띄우는 형태가 아니다. 우리가 원하는 모양에 안 맞으므로 **직접 ZStack 으로 만든다**.

기본 골격:

```swift
ZStack {
    // 1. 메인 컨텐츠 (사이드바 + 캘린더)
    HStack { ... }

    // 2. 다이얼로그 레이어 — 폴더 또는 카테고리
    if isAddFolderPresented {
        DialogBackdrop(isPresented: $isAddFolderPresented)
        AddFolderDialog(isPresented: $isAddFolderPresented)
    }
    if isAddCategoryPresented {
        DialogBackdrop(isPresented: $isAddCategoryPresented)
        AddCategoryDialog(isPresented: $isAddCategoryPresented)
    }
}
```

> 두 dialog state 가 동시에 true 가 될 일은 없다 (팝오버에서 둘 다 한꺼번에 켜지지 않음). 그래서 두 `if` 를 따로 두는 게 단순. 하나의 `enum` 으로 묶는 방법도 있는데 학습 부담만 늘어나니 일단 두 boolean 으로 간다.

### 2. dim 배경을 공통 컴포넌트로

배경 dim 은 두 다이얼로그가 똑같이 쓰는 부분이라 작은 컴포넌트로 분리하면 깔끔:

```swift
struct DialogBackdrop: View {
    @Binding var isPresented: Bool

    var body: some View {
        Color.black.opacity(0.4)
            .ignoresSafeArea()
            .onTapGesture {
                isPresented = false
            }
    }
}
```

> 같은 구조를 여러 곳에서 쓸 땐 view 로 빼는 게 자연 — Vue 의 작은 `.vue` 컴포넌트, Spring 의 helper bean 과 같은 발상.

### 3. `.onTapGesture` — 이벤트 전파 주의

> Vue 비유: `@click.self` 와 비슷한 발상. 자식에서 발생한 클릭이 부모로 올라오면 안 되는 케이스.

배경 (`Color.black.opacity`) 의 `.onTapGesture` 만 두면 동작은 한다. SwiftUI 의 `.onTapGesture` 는 해당 view 의 영역에 한정되므로, 카드 영역 안에서 발생한 탭은 dim 의 onTapGesture 를 발동시키지 않는다.

다만 카드 위에 또 다른 클릭 동작이 없는 빈 영역이 있고, 그 영역을 클릭하면 어떤 view 가 받느냐가 미묘해진다. 안전하게 카드 자체에 `.contentShape(Rectangle())` 을 주거나, 카드의 배경 view 자체가 hit-test 가 가능하면 OK.

요약:
- 배경 dim 에 `.onTapGesture` → 배경 클릭 시 닫기
- 카드 영역은 자기 영역이라 배경의 탭을 가로채므로 그대로 두면 됨
- 헷갈리면 카드에 `.contentShape(Rectangle())` 한 줄 추가

### 4. `.keyboardShortcut(.cancelAction)` — ESC 로 닫기

```swift
Button("취소") { isPresented = false }
    .keyboardShortcut(.cancelAction)   // ESC + Cmd+. 자동
```

`.cancelAction` 은 macOS 의 표준 "취소" 의미 — **ESC 키와 Cmd-마침표** 가 자동으로 묶인다. 별도 키 핸들러 없이도 ESC 닫기가 된다. **취소 버튼이 있다면 이 방법이 가장 idiomatic.**

> Java/Spring 비유는 없음 — SwiftUI 에만 있는 macOS HIG (Human Interface Guidelines) 표준 단축키 매핑.

### 5. (선택) `.transition` 으로 부드럽게 등장

다이얼로그가 갑자기 나타나는 게 어색하면 `withAnimation` + `.transition` 조합으로 페이드/스케일을 줄 수 있다.

```swift
withAnimation(.smooth(duration: 0.18)) {
    isAddFolderPresented = false
}

// 다이얼로그 view 에
.transition(.opacity.combined(with: .scale(scale: 0.96)))
```

> 기능 03 단계 03 (`.transition`) + 기능 07 단계 01 (`withAnimation` 함정) 참고.

## 구현 가이드

### 1. `AddFolderDialog.swift` & `AddCategoryDialog.swift` 신설 (placeholder)

둘 다 이번 단계에선 **빈 카드 + 취소/저장 버튼** 만. 폼은 다음 단계 (폴더) 와 그 다음 단계 (카테고리) 에서.

`JHCalendar/Features/Sidebar/AddFolderDialog.swift`:

```swift
import SwiftUI

struct AddFolderDialog: View {
    @Binding var isPresented: Bool

    var body: some View {
        VStack(spacing: 16) {
            Text("폴더 추가").font(.headline)
            Text("(단계 04 에서 입력 폼 추가 예정)")
                .foregroundStyle(.secondary)

            HStack {
                Button("취소") { isPresented = false }
                    .keyboardShortcut(.cancelAction)
                Spacer()
                Button("저장") { isPresented = false }
                    .keyboardShortcut(.defaultAction)
            }
        }
        .padding(24)
        .frame(width: 320)
        .background(.background)
        .clipShape(.rect(cornerRadius: 12))
        .shadow(color: .black.opacity(0.3), radius: 20, y: 8)
    }
}
```

`AddCategoryDialog.swift` 도 같은 구조 (`width: 360` 정도, 텍스트만 "카테고리 추가" 로).

> `.background(.background)` 는 시스템 동적 색상 — 라이트/다크 모드 자동 대응. `.white` 로 박으면 다크모드에서 어색.

### 2. `DialogBackdrop.swift` 신설 (선택, 공통 컴포넌트)

```swift
import SwiftUI

struct DialogBackdrop: View {
    @Binding var isPresented: Bool
    var body: some View {
        Color.black.opacity(0.4)
            .ignoresSafeArea()
            .onTapGesture { isPresented = false }
    }
}
```

> 별도 파일로 안 빼고 두 다이얼로그 안에 인라인으로 두어도 OK. 중복이 부담스러우면 분리.

### 3. `ContentView` 에 dim + dialog 레이어 추가

```swift
struct ContentView: View {
    @State private var isSidebarVisible = false
    @State private var isAddFolderPresented = false
    @State private var isAddCategoryPresented = false

    var body: some View {
        ZStack {
            HStack(spacing: 0) {
                Sidebar(
                    isAddFolderPresented: $isAddFolderPresented,
                    isAddCategoryPresented: $isAddCategoryPresented
                )
                .frame(width: isSidebarVisible ? 240 : 0, alignment: .leading)
                .clipped()

                ZStack(alignment: .topLeading) {
                    Color.clear
                    MonthlyCalendarView()
                    FloatingToolbar(isSidebarVisible: $isSidebarVisible)
                }
            }
            .overlay(alignment: .topLeading) { TrafficLightHoverArea() }

            // 다이얼로그 레이어 — 가장 위
            if isAddFolderPresented {
                DialogBackdrop(isPresented: $isAddFolderPresented)
                AddFolderDialog(isPresented: $isAddFolderPresented)
            }
            if isAddCategoryPresented {
                DialogBackdrop(isPresented: $isAddCategoryPresented)
                AddCategoryDialog(isPresented: $isAddCategoryPresented)
            }
        }
        .frame(minWidth: 900, minHeight: 600)
        .ignoresSafeArea()
    }
}
```

힌트:
- 단계 02 에서 넣었던 `onChange` 로그는 이제 빼도 됨 (다이얼로그 자체가 시각적 확인).
- `ZStack` 의 default alignment 는 `.center` 라서 다이얼로그 카드는 자동으로 가운데에 뜬다.

### 4. (선택) 등장/사라짐 애니메이션

```swift
if isAddFolderPresented {
    DialogBackdrop(isPresented: $isAddFolderPresented)
        .transition(.opacity)
    AddFolderDialog(isPresented: $isAddFolderPresented)
        .transition(.opacity.combined(with: .scale(scale: 0.96)))
}
```

`+` 메뉴에서 다이얼로그를 켜는 부분과 취소/배경 클릭으로 끄는 부분 모두 `withAnimation(.smooth(duration: 0.18)) { ... }` 으로 감싸기.
