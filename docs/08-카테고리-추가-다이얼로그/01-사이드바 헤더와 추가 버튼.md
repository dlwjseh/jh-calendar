# 단계 1: 사이드바 헤더 + `+` 버튼 (메뉴 토글)

## 학습 목표
- 사이드바 상단에 헤더 영역을 만들고, **우측 끝에** `+` 버튼을 둔다.
- `+` 버튼이 토글할 상태 `isAddMenuPresented` 를 **올바른 위치** 에 둔다.

## 사전 지식
- 기능 03 의 `@Binding<Bool>` 패턴 — 상태를 부모가 소유, 자식이 binding 으로 받기.
- 기능 04 의 `Sidebar.swift` 구조 — 현재 `VStack` 안에 폴더 목록만 있음.
- 기능 02 의 `HoverButton` — 호버 시 옅은 배경 + SF Symbol 라벨.

### "어디에 상태를 둬야 하지?"

`+` 버튼은 **사이드바 안에** 있다. 그리고 다음 단계에서 이 버튼에 **팝오버 (말풍선 메뉴)** 가 anchor 로 붙는다.

- 팝오버는 + 버튼 바로 옆에 떠야 하므로 → `.popover()` modifier 도 + 버튼이 있는 view 트리(=사이드바) 에서 붙는다.
- 따라서 `isAddMenuPresented` 상태도 **사이드바 안 (`@State`)** 에 두는 게 자연스럽다.
- 다이얼로그 상태 (`isAddFolderPresented` / `isAddCategoryPresented`) 는 다음 단계에서 따로 끌어올린다 — 다이얼로그는 사이드바를 **포함한 전체 화면** 을 덮어야 하므로 ContentView 가 소유.

> 기능 03 의 `isSidebarVisible` 와 살짝 다른 그림이다 — 거기선 자식 (사이드바 토글 버튼) 이 부모 (사이드바) 의 가시성을 바꿔야 했고, 그래서 **부모가 상태 소유 + 자식이 `@Binding`**. 이번엔 + 버튼과 팝오버가 **같은 사이드바 안** 에 있어서 그냥 로컬 `@State` 면 충분.
>
> Java/Spring 비유: 페이지 안에서만 쓰이는 fragment-local 상태는 페이지 자체가 들고 있어도 되고, 다른 컴포넌트가 같이 봐야 하는 상태는 컨트롤러로 올려야 하는 것과 같은 결.

## 구현 가이드

### 1. `Sidebar` 에 헤더 + `+` 버튼 추가

현재 `Sidebar.swift` 의 `VStack` 위에 헤더 행을 하나 둔다.

```swift
struct Sidebar: View {
    @State private var isAddMenuPresented = false   // 추가
    @State private var folders: [Folder] = Folder.sample

    var body: some View {
        VStack(alignment: .leading, spacing: 0) {
            // 헤더 (우측 끝에 + 버튼)
            HStack {
                Spacer()
                HoverButton {
                    print("+ 클릭, isAddMenuPresented = \(!isAddMenuPresented)")
                    isAddMenuPresented.toggle()
                } label: {
                    Image(systemName: "plus")
                        .font(.system(size: 14, weight: .medium))
                        .foregroundStyle(.primary)
                        .frame(width: 20, height: 20)
                }
            }
            .padding(.horizontal, 12)
            .padding(.top, /* 트래픽 라이트와 안 겹치게 */)

            // 기존 폴더 목록 (VStack)
            VStack(alignment: .leading, spacing: 30) {
                // ... 기존 내용 그대로
            }
        }
        .frame(width: 240, alignment: .leading)
        .frame(maxHeight: .infinity, alignment: .topLeading)
        .background(.gray.opacity(0.08))
    }
}
```

힌트:
- 기존 `.padding(.top, 40)` 은 헤더가 그 자리를 차지하니, 외부 컨테이너에서 빼고 헤더 자체의 `padding(.top)` 으로 옮기는 게 깔끔.
- 헤더 높이를 캘린더 위 플로팅 툴바와 시각적으로 맞추면 좋다. 정확한 값보단 **눈으로 보고 조정**.

### 2. (현재 단계엔 안 함) 팝오버 자체는 다음 단계

이번 단계는 **버튼만**. 클릭 시 `isAddMenuPresented` 가 토글되는지 `print` 로 확인하면 OK. 팝오버 UI 는 단계 02 에서.
