# 단계 4: 폴더 추가 다이얼로그

## 학습 목표
- `TextField` 로 폴더 이름을 입력받는다.
- 저장 버튼은 이름이 비어있으면 비활성화된다.
- 저장 시 입력값을 콘솔에 `print` 하고 다이얼로그를 닫는다. (실제 추가는 다음 기능에서.)

## Swift / SwiftUI 개념

### 1. `TextField` — Vue 의 `v-model` 과 같은 양방향 바인딩

```swift
@State private var name = ""

TextField("폴더 이름", text: $name)
    .textFieldStyle(.roundedBorder)
```

- 첫 인자 `"폴더 이름"` 은 **placeholder** (Vue 의 `:placeholder`).
- `text: $name` — `$` 는 `Binding<String>`. TextField 안 변경이 `name` 으로 흘러나오고, 외부에서 `name` 을 바꾸면 TextField 에도 반영. **정확히 `v-model="name"`**.
- `.textFieldStyle(.roundedBorder)` — macOS 에서 자연스러운 외곽선. 기본 스타일은 너무 평범하다.

빈 문자열 검사 (공백만 입력한 경우도 빈 것으로):

```swift
let isNameEmpty = name.trimmingCharacters(in: .whitespaces).isEmpty
```

> `String.trimmingCharacters(in:)` 는 Java 의 `String.strip()` 과 동일.

### 2. `.disabled(...)` — 조건부 버튼 비활성화

```swift
Button("저장") { save() }
    .disabled(name.trimmingCharacters(in: .whitespaces).isEmpty)
```

비활성 상태가 되면 시스템이 알아서 회색으로 칠하고 클릭도 무시. 별도 스타일링 불필요.

### 3. (선택) `@FocusState` — 다이얼로그가 뜨면 TextField 에 자동 포커스

```swift
@FocusState private var isNameFocused: Bool

TextField("폴더 이름", text: $name)
    .focused($isNameFocused)
    .onAppear { isNameFocused = true }
```

> `@FocusState` 는 SwiftUI 의 포커스 상태 관리 전용 프로퍼티 래퍼. `@State<Bool>` 이 아니라 `@FocusState<Bool>` — 시스템이 키 포커스와 양방향 동기화해 준다.

### 4. (선택) `.onSubmit` — Enter 키로 저장

```swift
TextField("폴더 이름", text: $name)
    .onSubmit { save() }
```

`Button("저장").keyboardShortcut(.defaultAction)` 가 이미 Enter 를 잡아준다면 `.onSubmit` 은 굳이 필요 없음. 둘 중 하나로 충분.

## 구현 가이드

### 1. `AddFolderDialog` 본격 구현

```swift
struct AddFolderDialog: View {
    @Binding var isPresented: Bool

    @State private var name: String = ""
    @FocusState private var isNameFocused: Bool   // 선택

    private var isSaveEnabled: Bool {
        !name.trimmingCharacters(in: .whitespaces).isEmpty
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 20) {
            Text("폴더 추가").font(.headline)

            VStack(alignment: .leading, spacing: 6) {
                Text("이름").font(.caption).foregroundStyle(.secondary)
                TextField("폴더 이름", text: $name)
                    .textFieldStyle(.roundedBorder)
                    .focused($isNameFocused)
            }

            HStack {
                Button("취소") { isPresented = false }
                    .keyboardShortcut(.cancelAction)
                Spacer()
                Button("저장") {
                    print("폴더 저장: name=\(name)")
                    isPresented = false
                }
                .keyboardShortcut(.defaultAction)
                .disabled(!isSaveEnabled)
            }
            .padding(.top, 4)
        }
        .padding(24)
        .frame(width: 320)
        .background(.background)
        .clipShape(.rect(cornerRadius: 12))
        .shadow(color: .black.opacity(0.3), radius: 20, y: 8)
        .onAppear { isNameFocused = true }
    }
}
```

### 2. 닫힐 때 입력값이 초기화되는가?

`AddFolderDialog` 가 `isAddFolderPresented` 가 `true` 일 때만 ZStack 안에서 렌더되도록 단계 03 에서 구성했다면, 닫혔다가 다시 열릴 때 view 가 **새로 만들어지면서 `@State name = ""`** 부터 시작. 별도 초기화 코드 불필요. (조건부 렌더 덕분.)

## 직접 구현하기
- [ ] `AddFolderDialog` 에 `@State var name: String = ""` 추가
- [ ] `TextField("폴더 이름", text: $name)` 자리에 두기
- [ ] `isSaveEnabled` 계산 프로퍼티 추가 (공백만 있는 경우도 false)
- [ ] 저장 버튼: `print` + `isPresented = false`, `.disabled(!isSaveEnabled)`
- [ ] (선택) `@FocusState` + `.onAppear { isNameFocused = true }` 로 자동 포커스
- [ ] 빌드 + 동작 확인:
  - [ ] `+` → 폴더 → 다이얼로그 등장, TextField 에 포커스
  - [ ] 이름 비어있을 때 저장 비활성, 입력하면 활성
  - [ ] 공백만 입력 → 저장 여전히 비활성
  - [ ] 저장 누르면 콘솔에 `폴더 저장: name=...` + 닫힘
  - [ ] 다시 열면 TextField 가 비어 있음

> 다 끝나면 "다 했어" 라고 알려줘.
