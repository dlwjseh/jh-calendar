# 카테고리 표시 필터 + 사이드바 상태 유지

## 목표
- 사이드바 카테고리 **체크박스**로 달력 이벤트를 보이고/숨긴다 (체크 → 표시, 해제 → 숨김).
- 사이드바를 **펼친 채 종료**하면 다음 실행 때도 펼쳐진 상태로 뜨게 한다 (상태 영속화).

## 의존 관계
- 사전 필요:
  - `04-사이드바-카테고리-UI` / `08-카테고리-추가-다이얼로그` — `Category` 모델, `CategoryRow` 체크박스 (`isChecked` 이미 존재·토글됨)
  - `11-달력-이벤트-표시` / `12-일-팝업` — `@Query` 로 이벤트를 가져와 그리는 지점
  - `19-이벤트-반복` (04단계) — **`#Predicate` 한계 → 인메모리 필터** 패턴 (그대로 재활용)
  - `03-사이드바-슬라이드` / `07-사이드바-토글-다듬기` — `ContentView.isSidebarVisible` 토글
- 이후 영향:
  - "폴더 단위 일괄 체크/해제", "이 카테고리만 보기" 같은 필터 UI 를 이 위에 올릴 수 있음.

## 단계 체크리스트
- [ ] 01 - 카테고리 체크 → 이벤트 표시/숨김 필터
- [ ] 02 - 사이드바 펼침 상태 유지 (`@AppStorage`)

## 이 기능에서 학습할 Swift / SwiftUI 개념

**새로 등장**:
- **관계(relationship) 순회 필터링** — `event.category?.isChecked` 로 다른 모델의 값을 보고 거르기
- **`@Observable`(SwiftData `@Model`) 반응성** — 왜 *뷰 body 안에서* `isChecked` 를 읽어야 토글 시 다시 그려지나
- **`@AppStorage`** — UserDefaults 기반 영속 상태 (JS `localStorage` 와 비슷)

**다시 쓰는 개념** (링크):
- `#Predicate` 한계 → 인메모리 필터 → [19-04 반복 펼치기 엔진](../19-이벤트-반복/04-반복-펼치기-엔진.md)
- `@State` → [01-타이틀바-호버표시/02-호버상태](../01-타이틀바-호버표시/02-호버상태.md)
- `@Query` / `#Predicate` → [11](../11-달력-이벤트-표시/README.md) / [12](../12-일-팝업/README.md)

## 범위 / 비범위
- **개별 카테고리 체크만.** 폴더 단위 일괄 토글은 이번 범위 밖.
- 카테고리 **없는(`category == nil`) 이벤트**의 표시 정책은 01 단계에서 한 가지로 정한다 (기본: 항상 표시).
