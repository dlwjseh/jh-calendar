# 이벤트 반복

## 목표
이벤트에 반복 규칙(매일 / 매주 X요일 / 매월 N일 / 매년 M월 N일)을 달 수 있게 한다.
다이얼로그는 **기본 필드만** 보여주고, "+추가" 말풍선에서 기능을 골라 펼치는 **확장형 구조**로 바꾼다 (반복은 그 첫 기능).
반복 이벤트는 **1건만 저장**하고, 화면에는 보이는 달 범위에서 해당 날짜마다 **펼쳐서(expand)** 표시한다.

  - `10-이벤트-추가-다이얼로그` — `AddEventDialog`, `EventDialogMode` enum (연관값)

- 이후 영향:
  - 수정/삭제 범위(이 날짜만 vs 전체), 종료일·횟수 → 이 위에 올림
  - "+추가" 확장 구조는 앞으로 추가될 이벤트 기능들(알림·위치 등)의 **공통 틀**

## 이 기능에서 학습할 Swift / SwiftUI 개념

**새로 등장**:
- **raw value enum** (`enum X: String`) + SwiftData 가 enum 을 저장하는 법 (`RawRepresentable` + lightweight migration)
- **`CaseIterable`** — `.allCases` 로 피커 옵션 자동 생성
- **`Picker` / `Menu`** 로 선택지 + **시작일에서 파생되는 동적 라벨**
- **`#Predicate` 의 한계** → 왜 반복 매칭을 인메모리로 옮겨야 하나
- **"가상 인스턴스" 모델** — 저장 1건 → 화면 N개 (iCalendar RRULE 의 축소판)

## UI 설계 (확정)
- 다이얼로그 기본 필드(카테고리·이벤트명·종일·시작·종료) 아래에 **"+추가" 버튼**.
- 누르면 사이드바와 같은 **말풍선**(`.popover`)이 뜨고, 거기서 "반복" 선택.
- 선택하면 다이얼로그 본문에 **반복 섹션이 끼워짐** + 섹션 헤더의 ✕ 로 다시 제거.
- 반복 피커는 **메뉴 드롭다운 한 줄** (`[반복 안 함 ▾]`) — Apple 캘린더식. "매주 목요일" 같은 긴 라벨은 시작일에서 자동 계산.

## 범위 / 비범위
- **단일·종일 이벤트 반복만.** 멀티데이 이벤트의 반복은 복잡 → 이번 범위 밖.
- **무한 반복만** (종료일·횟수 없음). 화면은 보이는 ~6주만 펼치므로 무한이어도 안전.
- 수정/삭제는 저장된 **1건(전체 시리즈)** 에 작동. "이 날짜만" 분기는 후속 기능.
- 반복 인스턴스를 일반 이벤트와 시각적으로 구분하는 표식(🔁)은 이번엔 안 넣음 (후속).
