# 단계 3: 반복 피커 + 저장 연결

## 학습 목표
- 01단계의 placeholder 섹션을 **메뉴 드롭다운 피커**로 교체한다.
- 5개 옵션의 라벨을 **시작일에서 동적으로 파생**한다 ("매주 목요일", "매년 5월 28일").
- 선택한 규칙을 저장/수정 시 `event.recurrence` 에 반영하고, 수정 다이얼로그 재오픈 시 복원한다.

## 사전 산출물
- 01단계: "+추가" → 말풍선 → `showRecurrence` 섹션 (placeholder).
- 02단계: `RecurrenceRule` enum + `Event.recurrence`.

## Swift / SwiftUI 개념

### `Picker` (메뉴 스타일)
선택지 하나를 고르는 표준 컨트롤. macOS 에서 `.pickerStyle(.menu)`(기본) 이면 드롭다운으로 뜬다.

```swift
Picker("반복", selection: $recurrence) {
    ForEach(RecurrenceRule.allCases, id: \.self) { rule in
        Text(label(for: rule)).tag(rule)
    }
}
.labelsHidden()
```

- `selection:` 에 `@State` 바인딩, 각 옵션은 `.tag(값)` 으로 식별.
- `RecurrenceRule.allCases`(02단계 `CaseIterable`) 를 그대로 옵션으로.
- **Vue 비교**: `<select v-model="recurrence"><option v-for=...>` 와 거의 1:1. `.tag` 가 `<option :value>` 역할.
- `Menu { Button(...) }` 로 직접 만들 수도 있지만, 단일 선택엔 `Picker` 가 더 적합(체크 표시·접근성 자동).

### 시작일에서 파생되는 동적 라벨
"매주 목요일" 의 "목요일", "매월 28일" 의 "28", "매년 5월 28일" 의 "5월 28일" 은 **모두 `startDate` 에서 계산**된다. 별도 입력 불필요 — 시작일만 있으면 결정된다.

라벨 만드는 함수(골격):
```swift
private func label(for rule: RecurrenceRule) -> String {
    switch rule {
    case .none:    return "반복 안 함"
    case .daily:   return "매일"
    case .weekly:  return "매주 \( /* startDate 의 요일명 */ )"
    case .monthly: return "매월 \( /* startDate 의 일 */ )일"
    case .yearly:  return "매년 \( /* startDate 의 월 */ )월 \( /* 일 */ )일"
    }
}
```

- 요일명: `DateFormatter` 에 `locale = ko_KR`, `dateFormat = "EEEE"` → "목요일". (DateFormatter 는 이미 12단계 `dayString` 등에서 사용.)
- 일/월 숫자: `Calendar.current.component(.day, from: startDate)`, `.month` → [Calendar-와-Date](../자주-쓰는-기술들/Calendar-와-Date.md#3-1-특정-컴포넌트-뽑기--componentfrom).
- `startDate` 가 바뀌면 라벨도 바뀌어야 한다 → `label(for:)` 이 `startDate` 를 읽는 일반 메서드이므로, 뷰가 다시 그려질 때 자동으로 새 라벨. (`startDate` 가 `@State` 라 변경 시 재렌더.)

> DateFormatter 를 매 렌더마다 새로 만드는 비용이 신경 쓰일 수 있는데, 이 규모(라벨 몇 개)에선 무시 가능하다. 굳이 캐싱 안 해도 OK — 거슬리면 `static let` 으로 빼는 정도.

## 구현 가이드

### 1) 상태 추가
```swift
@State private var recurrence: RecurrenceRule
```
`init` 에서 모드별 초기화:
- `.add` → `.none`
- `.edit(event)` → `event.recurrence`

또 **수정 모드로 열었는데 이미 반복이 걸려 있으면 섹션이 자동으로 펼쳐져야** 한다:
```swift
// init 안
_showRecurrence = State(initialValue: /* edit 이고 recurrence != .none 이면 true */)
```

### 2) placeholder → Picker 교체
01단계의 `Text("반복 설정 (다음 단계)")` 자리에 위 `Picker`. 섹션 헤더 ✕ 는 그대로 두되, ✕ 로 섹션을 닫을 때 `recurrence = .none` 으로도 되돌릴지 결정(권장: 닫으면 반복 해제).

### 3) 저장/수정에 반영
`AddEventDialog` 저장 버튼 `switch mode` 에 한 줄씩:
```swift
case .add:
    let event = Event(/* 기존 인자 */, recurrence: showRecurrence ? recurrence : .none)
    modelContext.insert(event)
case .edit(let event):
    // 기존 필드들...
    event.recurrence = showRecurrence ? recurrence : .none
```
> `showRecurrence` 가 꺼져 있으면 `.none` 으로 저장 — 섹션을 안 펼쳤으면 반복 없음.
