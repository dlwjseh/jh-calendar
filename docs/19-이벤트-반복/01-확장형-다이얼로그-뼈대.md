# 단계 1: 확장형 다이얼로그 뼈대

> 새 Swift/SwiftUI 개념 거의 없음 — 기존 `.popover` 말풍선 패턴 **재사용** + 조건부 섹션. 작업 가이드 중심.

## 작업 목표
- `AddEventDialog` 의 기본 필드(카테고리·이벤트명·종일·시작·종료) 아래에 **"+추가" 버튼** 을 둔다.
- 누르면 **말풍선(`.popover`)** 이 뜨고, 그 안에 "반복" 항목 하나.
- "반복" 선택 시 다이얼로그 본문에 **반복 섹션(지금은 placeholder)** 이 펼쳐지고, 섹션 헤더의 **✕** 로 다시 제거된다.
- 실제 반복 피커/저장은 03 단계. 이 단계는 **틀(펼침/접힘)만**.

## 사전 산출물
- `AddEventDialog.swift` (10단계 산출물) — 기본 폼이 있는 상태.
- 사이드바의 `.popover` + `AddMenuPopover` (08단계). 이 패턴을 본떠 온다.

## 재사용하는 것 (재설명 X — 링크)
- `.popover(isPresented:attachmentAnchor:arrowEdge:)` + 말풍선 메뉴 + `HoverButton` → [08-02 추가 메뉴 팝오버](../08-카테고리-추가-다이얼로그/02-추가%20메뉴%20팝오버.md), 실제 코드는 `Sidebar.swift` + `AddMenuPopover.swift`.
- `@State` 로 펼침/접힘 토글, `if ... { }` 조건부 뷰 → 이전 단계들에서 충분히 다룸.

## 구현 가이드
> 정답 풀코드 X. 골격과 힌트만.

### 1) 어떤 기능이 켜졌는지 상태로
지금은 반복 하나라 `Bool` 로 시작해도 충분하다.

```swift
@State private var isAddMenuPresented = false
@State private var showRecurrence = false   // 반복 섹션 펼침 여부
```

> 앞으로 기능이 여러 개로 늘면 `Bool` 여러 개보다 `Set<EventFeature>` 같은 게 깔끔해진다. **단, 지금 미리 추상화하지 말 것** — 1개일 땐 `Bool` 이 정답. 늘어날 때 리팩터링.

### 2) "+추가" 버튼 + 말풍선
기본 필드 `VStack` **아래**, 버튼 행 **위**에 둔다.

```swift
HoverButton {
    isAddMenuPresented.toggle()
} label: {
    Label("추가", systemImage: "plus")
        .font(.system(size: 12))
}
.popover(isPresented: $isAddMenuPresented, arrowEdge: .bottom) {
    // TODO: 반복 항목을 가진 작은 메뉴 (AddMenuPopover 본떠서)
}
```

말풍선 내용은 `AddMenuPopover` 처럼 **별도 작은 뷰** 로 빼도 되고, 항목이 하나뿐이라 인라인 `VStack` 으로 시작해도 된다. "반복" 클릭 시:
```swift
isAddMenuPresented = false
withAnimation(.smooth(duration: 0.25)) { showRecurrence = true }
```

> `Features/Event/` 는 sync group 이라 새 파일(예: `EventAddMenuPopover.swift`)을 만들어 두면 pbxproj 편집 없이 자동 인식된다 (18단계 `HolidayPopupRow` 와 동일).

### 3) 반복 섹션 placeholder + ✕
기본 필드 영역 안(또는 바로 아래)에 조건부로:

```swift
if showRecurrence {
    VStack(alignment: .leading, spacing: 8) {
        HStack {
            Text("반복").font(.system(size: 12)).foregroundStyle(.secondary)
            Spacer()
            Button {
                withAnimation(.smooth(duration: 0.25)) { showRecurrence = false }
            } label: { Image(systemName: "xmark") }
                .buttonStyle(.plain)
        }
        Text("반복 설정 (다음 단계)")   // placeholder — 03에서 실제 Picker 로 교체
            .foregroundStyle(.secondary)
    }
    .transition(.opacity.combined(with: .move(edge: .top)))
}
```

### 4) "+추가" 버튼 노출 조건 (선택)
이미 반복 섹션이 떠 있으면 "반복" 을 또 추가할 수 없어야 자연스럽다. 항목이 하나뿐인 지금은 말풍선에서 "반복" 을 비활성(`.disabled(showRecurrence)`) 하거나, 켜졌으면 +추가 자체를 숨겨도 된다.
