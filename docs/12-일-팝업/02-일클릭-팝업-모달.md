# 단계 2: 일 클릭 → 일 팝업 모달 (이벤트 목록)

## 학습 목표
- 깊은 자식(`DayCellView`)의 클릭을 `@Binding` 으로 `ContentView` 까지 끌어올린다.
- 기존 모달 패턴(`DialogBackdrop` + 카드)을 재사용해 그 날의 이벤트 목록 다이얼로그를 띄운다.

## 사전 지식
- 01 단계(호버) 완료된 `DayCellView`
- 기존 모달 패턴: `ContentView` 의 `eventDialog: EventDialogMode?` → `if let` → `DialogBackdrop` + `AddEventDialog`
- 바인딩 전달 패턴: `FloatingToolbar(eventDialog: $eventDialog)` (이미 코드에 있음)
- `eventsByDay(_:)` 순수함수 (`EventIndex.swift`), `@Query` (11 에서 사용)

## Swift / SwiftUI 개념 (이 단계에서 새로 다루는 것만)

### 1) 버튼이 아닌 뷰를 탭 가능하게 — `contentShape` + `onTapGesture`
`Button` 으로 셀 전체를 감싸면 내부 이벤트 행까지 버튼 스타일에 먹힌다. 대신 일반 뷰에 제스처를 단다:

```swift
.contentShape(Rectangle())   // 투명한 영역까지 히트 테스트 대상에 포함
.onTapGesture { onSelectDay(cell.date) }
```
- `onTapGesture` 는 11 의 `DialogBackdrop` 에서 본 것과 동일.
- `contentShape(Rectangle())` 가 핵심: 셀 안 빈 공간(투명)도 클릭으로 잡으려면 명시해야 한다. (JS 로 치면 컨테이너 `div` 에 `onClick` 달되 빈 영역도 먹히게 하는 것과 비슷.)

### 2) 상태 끌어올리기 (state lifting)
셀이 직접 모달을 띄우지 않는다(11 의 "멍청한 셀" 연장). "이 날 눌렸다"만 부모로 올린다.

- `DayCellView` → `var onSelectDay: (Date) -> Void` (클로저 주입 — `onDismiss` 와 같은 방식)
- `MonthlyCalendarView` → `@Binding var dayPopup: Date?` 를 새로 받고, 셀 콜백에서 `dayPopup = cell.date` 로 세팅
- `ContentView` → `@State private var dayPopup: Date? = nil` 추가, `MonthlyCalendarView(dayPopup: $dayPopup)` 로 주입

> Vue 로 치면: 자식이 `emit('select', date)`, 부모가 `v-model`/state 로 받기. Java 면 콜백 인터페이스를 생성자로 주입.

### 3) 리프 다이얼로그의 범위 한정 `@Query`
`ContentView` 는 이벤트 인덱스를 모른다(그게 `MonthlyCalendarView` 안에 있음). 굳이 끌어올리지 말고, **`DayPopupDialog` 가 자기 `@Query` 로 직접** 그 날 이벤트만 추려라.

```swift
struct DayPopupDialog: View {
    let date: Date
    @Query(sort: \Event.startDate) private var allEvents: [Event]

    private var dayEvents: [Event] {
        let cal = Calendar.current
        let key = cal.startOfDay(for: date)
        // eventsByDay 재사용해서 그 날 버킷만 꺼내기
        return eventsByDay(allEvents)[key] ?? []   // TODO
    }
    ...
}
```
- 11 의 순수함수(`eventsByDay`)를 그대로 재사용 → 로직 중복 없음.
- 다이얼로그가 열렸을 때만 평가되니 비용 무시 가능(조기 최적화 불필요).

## 구현 가이드
> 정답 풀코드는 제공하지 않는다.

**A. `DayCellView`**
- `var onSelectDay: (Date) -> Void` 추가.
- 루트에 `.contentShape(Rectangle())` + `.onTapGesture { onSelectDay(cell.date) }`.

**B. `MonthlyCalendarView`**
- `@Binding var dayPopup: Date?` 추가.
- `DayCellView(... , onSelectDay: { dayPopup = $0 })` 로 연결.
- `#Preview` 가 깨지면 `MonthlyCalendarView(dayPopup: .constant(nil))` 로.

**C. `ContentView`**
- `@State private var dayPopup: Date? = nil`.
- `MonthlyCalendarView(dayPopup: $dayPopup)`.
- 기존 `if let mode = eventDialog { ... }` 블록을 본떠 새 블록:

```swift
if let day = dayPopup {
    DialogBackdrop {
        withAnimation(.smooth(duration: 0.3)) { dayPopup = nil }
    }.transition(.opacity)
    DayPopupDialog(date: day /*, 콜백은 03·04 에서 */)
        .transition(.opacity.combined(with: .scale(scale: 0.96)))
}
```

**D. `DayPopupDialog` (신규, `Features/Event/` 에)**
- `date` + 자체 `@Query`.
- 헤더: 날짜 텍스트(예: `M월 d일(E)` — `Date.FormatStyle` 또는 `DateFormatter`, 11-5 에서 다룬 포맷). 우상단 `＋` 버튼 자리는 **지금은 비워두거나 더미**(03 에서 연결).
- 목록: `dayEvents` 를 `ForEach`. 한 행 = 색점(`Circle().fill(e.color)`) + 이름 + 오른쪽에 `종일` 또는 시작시각(11-5 의 `e.startDate, format:` 재사용). 이벤트 0개면 "일정 없음" 한 줄.
- 카드 외형은 `AddEventDialog` 의 `.background/.clipShape/.shadow/.frame(width:)` 를 참고해 톤 맞추기.
