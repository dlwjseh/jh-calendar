# 단계 1: 일 셀 호버 배경

> 새 Swift/SwiftUI 개념 없음 — `onHover` + `@State` + 조건부 `.background()` 는 모두 기존 범위.
> `onHover`/`@State` → `01-타이틀바-호버표시` (`TrafficLightHoverArea.swift`), `HoverButton.swift` 참고. **작업 가이드**만 둔다.

## 작업 목표
`DayCellView` 에 마우스를 올리면 그 셀 배경이 살짝 강조됐다가, 벗어나면 원래대로 돌아온다.

## 사전 산출물
- `DayCellView` (11 까지의 상태: 날짜 + 이벤트 바/시각 렌더, `.overlay` 로 1px 테두리)

## 작업 가이드

**1) 호버 상태**
- `DayCellView` 에 `@State private var isHovered = false`.
- 셀 루트(`VStack`)의 `.frame(...)` 다음에 `.onHover { isHovered = $0 }`.

**2) 배경 적용 — 순서 주의**
- `.background(...)` 를 **`.overlay`(테두리)·`.padding` 보다 안쪽**(먼저)에 두어야 셀 영역만 칠해진다.
- 색은 은은하게. 예: `Color.primary.opacity(isHovered ? 0.06 : 0)` 또는 `Color.accentColor.opacity(...)`.
- 부드럽게: `.animation(.easeInOut(duration: 0.12), value: isHovered)`.

```swift
.frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .top)
.padding(.top, 6)
.background(Color.primary.opacity(isHovered ? 0.06 : 0))   // TODO: 위치·색 조정
.overlay(Rectangle().stroke(Color.gray.opacity(0.2), lineWidth: 0.5))
.onHover { isHovered = $0 }                                  // TODO
// .animation(...)  // TODO: 원하면
```

**3) (선택) 다른 달 셀 처리**
- 다른 달(`!cell.isInCurrentMonth`) 셀에는 호버 강조를 안 줄지 결정. 주려면 그대로, 안 주려면 `isHovered && cell.isInCurrentMonth` 로 게이트.

## 직접 구현하기
- [ ] `@State isHovered` + `.onHover`
- [ ] 조건부 `.background` (테두리 안쪽 위치 확인)
- [ ] 마우스 올렸다 뗄 때 자연스럽게 바뀌나 (애니메이션은 취향)

> 다 끝나면 "다 했어" 라고 알리면 리뷰.
