# 단계 3: 카테고리 칩 호버 + 손모양 커서

> 새 개념 없음. 01 의 `.onHover`/`@State isHovered` + 02 의 `.pointerStyle(.link)` 를 카테고리 칩에 합쳐 적용.
> `.onHover` → [01-03 호버 영역과 상태 관리](../01-타이틀바-호버표시/03-호버%20영역과%20상태%20관리.md), `.pointerStyle(.link)` → [02-04 호버 커서 변경](../02-상단-플로팅-툴바/04-호버%20커서%20변경.md) 참고. 두 modifier 가 한 컴포넌트에서 같이 따라오는 사례는 [02-05 HoverButton](../02-상단-플로팅-툴바/05-HoverButton%20분리와%20hover%20배경.md) 도 동일.

## 작업 목표
`AddEventDialog` 의 카테고리 칩 위에 마우스를 올리면:
- 커서가 **손모양**으로 바뀐다 (`.pointerStyle(.link)`)
- 칩에 **호버 강조** (배경 옅게 또는 보더 진하게) 가 들어간다

선택된 칩과 안 선택된 칩의 호버 표현은 다를 수 있다 — 사용자 취향대로.

## 사전 산출물
- `CategoryChip.swift` — `@Binding selectedCategory`, `let category`, `borderColor`/`backgroundColor` 가 선택 상태로 분기하고 있음. 호버 상태는 아직 없음.

## 작업 가이드

**1) 호버 상태 추가**

```swift
struct CategoryChip: View {
    @Binding var selectedCategory: Category?
    let category: Category

    @State private var isHovered = false   // TODO

    // ...
}
```

**2) 색 계산식에 호버 반영**

선택/비선택 × 호버/비호버 = 4가지인데, 모두 다 분기할 필요는 없다. 한 축만 추가하면 충분:

```swift
private var backgroundColor: Color {
    if selectedCategory == category {
        return category.color.opacity(isHovered ? 0.18 : 0.1)   // 선택 + 호버 → 살짝 진하게
    } else {
        return isHovered
            ? Color(.windowBackgroundColor).opacity(0.6)        // 비선택 + 호버
            : Color(.windowBackgroundColor)
    }
}
```

- 정확한 수치는 사용자 취향. 핵심은 "**호버일 때 0.05~0.10 정도 시각 변화**" 가 있다는 것.
- `borderColor` 도 비슷한 방식으로 강조할 수 있음(선택: `category.color`, 비선택+호버: `category.color.opacity(0.5)` 등). 안 해도 OK.

**3) `.onHover` + `.pointerStyle(.link)` 부착**

```swift
.contentShape(Capsule())
.onTapGesture { selectedCategory = category }
.onHover { isHovered = $0 }            // TODO
.pointerStyle(.link)                    // TODO
```

- 기존 `.contentShape(Capsule())` + `.onTapGesture` 의 끝에 두 줄 추가. 모디파이어 순서는 자유.
- `.pointerStyle(.link)` 는 macOS 15+ 전용 — 02-04 에서 다뤘듯 그대로 사용 가능.

## 직접 구현하기
- [ ] `@State private var isHovered = false` 추가
- [ ] `backgroundColor`(또는 `borderColor`) 계산에 `isHovered` 반영
- [ ] 칩 끝에 `.onHover { isHovered = $0 }` + `.pointerStyle(.link)` 추가
- [ ] 칩 위에 마우스를 올리면 커서가 손모양으로 바뀌는지
- [ ] 호버 시 배경/보더가 시각적으로 살짝 변하는지
- [ ] 호버 → 클릭 → 선택된 상태에서도 호버 효과가 자연스러운지 (선택색 위에 호버 강조)

## 자가 점검
- 빌드 통과?
- 마우스가 칩을 떠나면 호버 강조가 즉시 해제되는지? (`.onHover { $0 == false }` 도 정상 호출되는지)
- 여러 칩 사이를 빠르게 이동해도 두 칩이 동시에 호버 상태가 되지 **않는지**?
- 퀴즈: `.onHover` 는 어떤 영역에서 발화하는가 — `.contentShape(Capsule())` 이 어떤 역할을 하는지 다시 한 번 생각해 보기.
