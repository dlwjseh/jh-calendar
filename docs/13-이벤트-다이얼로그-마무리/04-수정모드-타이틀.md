> 새 개념 없음. `EventDialogMode` enum 의 `switch mode` 패턴을 **표시 텍스트 계산** 에 한 번 더 적용.
> enum 연관값 → [10-02 AddEventDialog UI](../10-이벤트-추가-다이얼로그/02-AddEventDialog%20UI.md), [12-04](../12-일-팝업/04-이벤트클릭-수정-프리필완성.md) 참고.

## 작업 목표
`AddEventDialog` 의 헤더 타이틀이 모드에 따라 분기된다.
- `.add` → "이벤트 추가" (기존)
- `.edit` → "이벤트 수정"

## 사전 산출물
- `AddEventDialog.swift` — `let mode: EventDialogMode` (`.add(Date)` / `.edit(Event)`).
- 현재 헤더는 하드코딩:
  ```swift
  HStack(spacing: 5) {
      Image(systemName: "calendar.badge.plus")
      Text("이벤트 추가")
  }
  ```

## 작업 가이드

**1) 타이틀을 computed property 로**

저장 로직에서 이미 `switch mode { case .add: ... ; case .edit(let event): ... }` 를 쓰고 있다. **표시용 텍스트도 같은 방식**:

```swift
private var title: String {
    switch mode {
    case .add:  "이벤트 추가"
    case .edit: "이벤트 수정"
    }
}
```

- `switch` 가 표현식처럼 값을 반환하는 형태 (Swift 5.9+) — 이미 `borderColor` / `backgroundColor` 같은 computed property 에서 익숙한 패턴.

**2) 헤더에 적용**

```swift
HStack(spacing: 5) {
    Image(systemName: "calendar.badge.plus")
    Text(title)   // TODO
}
```

연관값(`Date` / `Event`)은 여기선 안 써도 되니 `case .add:`, `case .edit:` 만으로 충분 (`let _` 도 불필요).

## 직접 구현하기
- [ ] `private var title: String { ... }` 추가
- [ ] 헤더 `Text("이벤트 추가")` → `Text(title)` 로 교체
- [ ] 일 팝업에서 `＋` → "이벤트 추가" 헤더로 열리는지
- [ ] 일 팝업에서 이벤트 행 클릭 → "이벤트 수정" 헤더로 열리는지
