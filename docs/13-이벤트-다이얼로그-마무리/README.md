# 이벤트 다이얼로그 마무리 (작은 수정사항)

## 목표
이벤트 추가/수정 다이얼로그(`AddEventDialog`)의 자잘한 UX 마감.

1. **시작일이 종료일을 추월하면 종료일 자동 보정** (종일/시간지정에 따라 분기)
2. **시·분 칸에서 ↑/↓ 화살표로 1씩 증감**
3. **카테고리 칩 호버 효과 + 손모양 커서**
4. **`.edit` 모드일 때 다이얼로그 타이틀 "이벤트 수정"**

> 4개 모두 **이미 배운 스킬을 새 위치에 적용**하는 작은 작업.
> 새로 등장하는 Swift / SwiftUI 개념은 없으므로 단계 md 는 "Swift / SwiftUI 개념" 섹션을 통째로 생략하고 **작업 가이드** 만 둔다.

## 의존 관계
- 사전 필요:
  - `10-이벤트-추가-다이얼로그` — `AddEventDialog`, `BorderlessTimePicker`, `CategoryChip`
  - `12-일-팝업` — `.edit(Event)` 분기 (수정 모드 진입 경로)
- 이후 영향: 없음 (다음 큰 단위는 멀티 데이 이벤트 렌더링)
