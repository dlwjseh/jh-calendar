# 단계 2: 년월 헤더 + 요일 헤더

## 학습 목표
- `Date` → `"2026년 5월"` 같은 사람 읽기용 문자열 변환을 **`DateFormatter`** 로 처리한다.

## Swift / SwiftUI 개념

### 1) `DateFormatter` — 새 개념
- `Date ↔ String` 변환기. Java 의 `DateTimeFormatter` 와 거의 같은 위상.
- **재사용** 이 권장됨 — 만드는 비용이 작지 않아서. View 안에서는 `static` 프로퍼티로 한 번 만들어 두고 쓰는 게 관용.

```swift
private static let yearMonthFormatter: DateFormatter = {
    let f = DateFormatter()
    f.locale = Locale(identifier: "ko_KR")   // "5월" 같은 한글 출력
    f.dateFormat = "yyyy년 M월"               // 패턴은 Unicode TR35
    return f
}()
```

- 패턴 문자 메모:
  - `y` = 연 (보통 4자리는 `yyyy`)
  - `M` = 월 (1~12). `MM` 이면 `05`, `M` 이면 `5`
  - `d` = 일 / `E` = 요일 / `a` = AM/PM …
  - 대소문자 의미가 다르다 (`m` 은 분, `M` 은 월). Java 와 동일.

### 2) `frame(maxWidth: .infinity)` — 균등 분할 트릭
- 자식 view 에 `.frame(maxWidth: .infinity)` 를 주면 **부모가 허락하는 만큼 가로로 늘어남**.
- `HStack` 자식 7개 모두에 같은 modifier 를 걸면 **남는 공간을 균등하게 나눠 가짐** → 7등분.
- Vue/HTML 의 `flex: 1` 과 같은 발상.

```swift
HStack(spacing: 0) {
    ForEach(weekdayLabels, id: \.self) { label in
        Text(label)
            .frame(maxWidth: .infinity)   // ← 핵심
    }
}
```

> `.infinity` 라고 진짜 무한대로 늘어나는 건 아니고 "부모가 주는 한도까지" 의 의미. SwiftUI 의 레이아웃 협상 결과.

### 3) 텍스트 정렬
- `Text` 자체는 한 줄짜리면 좌우 정렬 의미가 없음. **frame 의 가운데 정렬** 이 본체.
- `frame(maxWidth: .infinity)` 만 주면 기본이 가운데 정렬이라 이번 요구사항 ("중앙정렬") 에 그대로 부합.
- 명시하려면 `.frame(maxWidth: .infinity, alignment: .center)`.

## 구현 가이드

### 만들/수정할 파일
- `JHCalendar/Features/MonthlyCalendar/MonthlyCalendarView.swift` — 단계 01 에서 검증용으로 만들었다면 본격적인 형태로 다듬는다. 안 만들었다면 새로 생성.

### View 골격
```swift
import SwiftUI

struct MonthlyCalendarView: View {
    // 단계 03 에서 @State 로 바꿔 월 이동을 받을 수 있게 할 여지가 있지만
    // 이번 기능에선 "현재 달만" 이므로 일단 상수로 둬도 충분.
    private let referenceDate = Date()

    private static let yearMonthFormatter: DateFormatter = {
        let f = DateFormatter()
        f.locale = Locale(identifier: "ko_KR")
        f.dateFormat = "yyyy년 M월"
        return f
    }()

    private let weekdayLabels = ["일", "월", "화", "수", "목", "금", "토"]

    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            // 년월 헤더
            Text(Self.yearMonthFormatter.string(from: referenceDate))
                .font(.title2)
                // TODO: 굵기/색 등 디테일은 취향껏

            // 요일 헤더
            HStack(spacing: 0) {
                ForEach(weekdayLabels, id: \.self) { label in
                    Text(label)
                        .frame(maxWidth: .infinity)
                        // TODO: 폰트/색 정리 (.secondary 등)
                }
            }

            // 단계 03 에서 LazyVGrid 가 들어올 자리
            Spacer()  // 잠깐 자리 차지용
        }
        .padding()
    }
}

#Preview {
    MonthlyCalendarView()
}
```

### `ContentView` 연결
빈 `ZStack` 안에 `MonthlyCalendarView()` 를 정식으로 끼운다. 단계 01 에서 임시로 넣어놨다면 그 자리에 그대로.

```swift
ZStack(alignment: .topLeading) {
    Color.clear
    MonthlyCalendarView()                    // ← 메인 영역
    FloatingToolbar(isSidebarVisible: $isSidebarVisible)
}
```

> `FloatingToolbar` 는 그대로 위에 떠 있어야 하니까 **MonthlyCalendarView 보다 뒤에 선언** 해서 z 순서를 위로 올린다. (또는 `.zIndex` 명시.)

### 디테일 가이드
- 년월 텍스트의 좌측 패딩 / 폰트는 이미지와 비슷하게. (정확한 수치는 사용자가 시각적으로 맞추기.)
- 요일 헤더 텍스트 색은 약간 흐리게 (`.foregroundStyle(.secondary)`) 가 보통.
- 일요일/토요일을 빨강/파랑으로 칠하고 싶다면 — 이번 기능 범위 밖. 후속에서 추가하면 됨.
