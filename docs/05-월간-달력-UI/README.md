# 월간 달력 UI

## 목표
사이드바 오른쪽 메인 영역에 **월간 달력 (한 달 한 화면)** 을 그린다.
- **상단**: 년월 헤더 (예: `2026년 5월`)
- **중간**: 요일 헤더 — `일 월 화 수 목 금 토` (한글, 가로 7등분, 가운데 정렬)
- **하단**: 날짜 그리드 — 흐린 회색 구분선으로 칸을 나누고, 각 칸 **위쪽 가운데** 에 일(day) 숫자만 표시

> 이번 기능은 **현재 달만 정적으로** 그린다. 이전/다음 달 이동, 날짜 클릭, 오늘 강조 같은 인터랙션은 본 기능 범위 밖 — 후속 기능으로 분리.

> 주 단위는 **4~6주 가변** — 그 달이 실제로 차지하는 주 수만큼만 행을 만든다. (5주짜리 달은 5행, 6주짜리 달은 6행.) 첫 주의 일요일 ~ 마지막 주의 토요일 범위를 채우므로 앞뒤로 **이전달 끝 / 다음달 시작** 날짜가 일부 들어간다.

## 의존 관계
- 사전 필요: 기능 03 (사이드바 슬라이드) — 메인 영역이 사이드바와 분리되어 있어야 함. 본 기능은 메인 영역(현재 빈 `ZStack` 안)에 들어간다.
- 이후 영향:
  - 월 이동 / 오늘 강조 / 날짜 클릭 → 별도 기능
  - 실제 이벤트 표시 (EventKit 연동) → 별도 기능

## 단계 체크리스트
- [ ] 01 - 데이터 모델: 표시할 날짜 배열 만들기
- [ ] 02 - 년월 헤더 + 요일 헤더 (정적 텍스트 영역)
- [ ] 03 - 날짜 그리드 (LazyVGrid + 셀 + 회색 구분선)

## 이 기능에서 학습할 Swift / SwiftUI 개념
- **Foundation `Date` / `Calendar` / `DateComponents`** — Swift 의 날짜 3종 세트. Java 의 `Instant` / `Calendar` / `LocalDate(Time)` 셋이 한 묶음으로 묶인다고 보면 됨.
- **`Calendar.current` + `Locale`** — 시스템/사용자 로케일 기반 달력 연산 (요일 시작 요일, 한 달의 길이 등).
- **`DateFormatter`** — `Date` ↔ `String` 변환. Java 의 `DateTimeFormatter` 와 비슷.
- **`LazyVGrid` + `GridItem`** — 2차원 그리드 레이아웃. 컬럼 정의 배열을 넘기고 자식을 1D 로 흘려보내면 자동 줄바꿈.
- **`overlay` / `border` / `Divider`** — 셀 경계선 그리기 옵션 비교.
- **셀 컴포넌트 분리** — Day 1칸을 별도 view 로 빼서 재사용 (04 의 Row 분리와 같은 패턴).
- **`frame(maxWidth: .infinity)` 균등 분할** — HStack 안에서 자식이 동일 폭을 차지하게 하는 표준 트릭.

## 결과물 (이 기능 완료 후)
- 메인 영역 상단에 `2026년 5월` 같은 년월 텍스트.
- 그 아래 `일 월 화 수 목 금 토` 한글 요일 헤더가 가로 7등분으로 표시.
- 그 아래 4~6주 가변의 날짜 그리드. 각 칸은 흐린 회색 선으로 구분, 칸 위쪽 가운데에 일 숫자.
- 이번 달이 아닌 칸 (앞뒤로 비어 보이는 칸) 의 숫자는 흐리게 표시.
- 인터랙션은 없음 (다음 기능에서 추가).

## 파일 구조 (예정)
```
JHCalendar/Features/MonthlyCalendar/
├── MonthlyCalendarView.swift   ← 단계 02~03 에서 채울 메인 컨테이너
├── CalendarMath.swift          ← 단계 01 신설 (DayCell, 그리드 날짜 계산 함수)
└── DayCellView.swift           ← 단계 03 신설 (한 칸 셀 컴포넌트)
```

> 폴더 이름은 `Calendar` 가 아니라 `MonthlyCalendar` 로 — Foundation 의 `Calendar` 타입과 헷갈리지 않게 + 추후 다른 형태의 캘린더 뷰 (주간/미니 등) 와 구분.
