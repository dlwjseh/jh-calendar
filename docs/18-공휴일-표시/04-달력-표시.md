# 단계 4: 달력 셀에 공휴일 표시

> 이 단계는 이전 단계에서 익힌 SwiftUI 조합 패턴만 쓴다 — 새 Swift/SwiftUI 개념 없음. 작업 가이드 + 디자인 결정만.

## 작업 목표
- `byDay` 사전을 `DayCellView` 까지 전달.
- 공휴일이 있는 셀의 **일 숫자를 빨강** 으로 (일요일과 동일 — `textColor` 우선순위 갱신).
- 일 셀 안 일정 영역 상단에 공휴일 이름을 한 줄 표시.
- 멀티데이 이벤트 / 종일 이벤트와의 시각적 충돌이 없게 자리잡기.

## 사전 산출물
- [03-HolidayStore-캐싱](03-HolidayStore-캐싱.md) 완료 — `HolidayStore.byDay: [Date: Holiday]` 가 채워져 있음.
- `MonthlyCalendarView` 에서 `@EnvironmentObject var holidayStore` 접근 가능.

## 디자인 결정

### 표시 방식: 일 숫자 색 + 공휴일 라벨

| 요소 | 처리 |
|---|---|
| 일 숫자 색 | 빨강 (일요일 같은 톤). 단, 오늘 셀이면 17 단계 규칙대로 흰색 유지. |
| 공휴일 라벨 위치 | 일 숫자 바로 아래, 멀티데이 영역 (`reservedTop`) 위. |
| 라벨 스타일 | 빨강 텍스트, 작은 폰트 (10~11pt). 배경 없이 텍스트만이 macOS Calendar 결. |
| 여러 공휴일이 같은 날 | 거의 없음 (대체공휴일이 본 공휴일을 덮는 식). 1건만 가정. 2건 이상이면 첫 1건만. |
| 사용자 이벤트와 공존 | 공휴일 라벨이 위, 그 아래에 기존 single-day 이벤트들이 자연 흐름. |

> 대안 (참고): 옅은 빨강 둥근 배경 + 흰 글자로 "이벤트 바" 처럼 그리는 결도 가능. 단, 빨강 시각 자극이 강해져 화면이 빨개짐 — macOS Calendar 보다 Google Calendar 결. **본 단계는 텍스트만** 으로 가고, 회고에서 사용자가 바꾸고 싶으면 그때.

### 셀 안 layout 구조 (현재 → 변경 후)

현재:
```
VStack {
  Text(day) [원형 배경 if today]
  Spacer(reservedTop)         ← 멀티데이 공간
  VStack { 단일 이벤트들 }
}
```

변경 후:
```
VStack {
  Text(day) [원형 배경 if today]
  if let holiday { Text(holiday.name).foregroundStyle(.red) }   ← 추가
  Spacer(reservedTop)
  VStack { 단일 이벤트들 }
}
```

- 공휴일이 없으면 그 자리는 0 높이 — 기존 layout 유지.
- "단일 이벤트 + 공휴일" 모두 표시되는 셀에서 잘림이 없게 `maxVisible` (3) 카운팅에 공휴일을 1로 포함시킬지 결정.

### `maxVisible` 카운팅에 공휴일 포함?

현재 `DayCellView`:
```swift
private let maxVisible = 3
private var singleDayBudget: Int {
    max(0, maxVisible - multidayLaneCount)
}
```

공휴일 한 줄을 항상 표시하려면, 멀티데이 + 공휴일이 차지하는 줄 수만큼 single-day budget 을 줄여야 한다:

```swift
private var holidayLaneCount: Int { holiday == nil ? 0 : 1 }
private var singleDayBudget: Int {
    max(0, maxVisible - multidayLaneCount - holidayLaneCount)
}
```

> 의도: 공휴일은 항상 보이는 게 더 중요. 사용자 이벤트가 +N 으로 접히는 게 자연스러움.

## 구현 가이드

### 1) `MonthlyCalendarView` — `holidayStore` 사용

```swift
@EnvironmentObject private var holidayStore: HolidayStore

// WeekRowView 호출 시 holidaysByDay 전달
WeekRowView(
    row: row,
    eventsByDayIndex: singleDayEventsByDayIndex,
    weekMultidays: multidaysByWeek[...] ?? [],
    holidaysByDay: holidayStore.byDay      // 새 파라미터
) { ... }
```

### 2) `WeekRowView` — prop 추가 + DayCellView 로 forward

```swift
let holidaysByDay: [Date: Holiday]

DayCellView(
    cell: cell,
    events: eventsByDayIndex[cal.startOfDay(for: cell.date)] ?? [],
    multidayLaneCount: ...,
    holiday: holidaysByDay[cal.startOfDay(for: cell.date)],   // 새 파라미터
    onSelectDay: onSelectDay
)
```

### 3) `DayCellView` — `holiday` 표시 + `textColor` 갱신

```swift
let holiday: Holiday?

private var isHoliday: Bool { holiday != nil }
private var holidayLaneCount: Int { isHoliday ? 1 : 0 }
private var singleDayBudget: Int {
    max(0, maxVisible - multidayLaneCount - holidayLaneCount)
}

private var textColor: Color {
    if isToday { return .white }            // 17 단계 규칙 유지
    if !cell.isInCurrentMonth { return .secondary }
    if isHoliday { return .red }             // ← 추가
    switch cell.weekday {
        case 1:  return .red
        case 7:  return .blue
        default: return .primary
    }
}
```

> 우선순위:
> 1. isToday → 흰색
> 2. !isInCurrentMonth → secondary
> 3. isHoliday → red
> 4. 일요일 → red
> 5. 토요일 → blue
> 6. 평일 → primary

body 에 라벨 한 줄 추가:

```swift
VStack(spacing: 0) {
    Text("\(cell.day)") ...
    
    if let holiday {                          // ← 추가
        Text(holiday.name)
            .font(.system(size: 10, weight: .semibold))
            .foregroundStyle(.red)
            .lineLimit(1)
            .padding(.horizontal, 7)
            .padding(.bottom, 2)
            .frame(maxWidth: .infinity, alignment: .leading)
    }
    
    Spacer().frame(height: reservedTop)
    VStack { ... single-day events ... }
}
```

> 함정: 공휴일 라벨의 padding 이 single-day 이벤트의 padding 과 어긋나면 정렬이 어색. 기존 single-day allDay bar 의 `.padding(.horizontal, 7)` 와 맞춤.

### 4) "다른 달" 의 공휴일 처리

- `isInCurrentMonth == false` 인 셀에 공휴일이 있으면? — 현재 분기로는 글자색 `.secondary` 가 우선, 라벨도 안 보이는 게 자연. 또는 라벨을 회색으로 흐리게.
- 본 단계 결정: **다른 달 셀의 공휴일 라벨은 표시하지 않음** (`if let holiday, cell.isInCurrentMonth`).

### 5) 빌드 + 시각 확인

```bash
xcodebuild -project JHCalendar.xcodeproj -scheme JHCalendar -configuration Debug build
```

확인 사항:
- 1/1, 3/1, 5/5, 6/6, 8/15, 10/3, 10/9, 12/25 등에 빨강 일 숫자 + 공휴일 이름.
- 5/5 (어린이날) + 사용자 이벤트가 있는 경우 → 공휴일이 위, 이벤트들이 아래.
- 멀티데이 + 공휴일 겹친 셀 → reservedTop + 공휴일 라벨 둘 다 자연스럽게.
- 오늘이 공휴일 (예: 1/1 직접 시스템 날짜로 시뮬레이션) → 일 숫자는 흰색 + 빨강 원, 그 아래 빨강 공휴일 라벨.

## 자가 점검
- 빌드 + 실행 OK?
